Data formats

Panels first

Automatic XY-cut detection with manual drawing, merging, numbering and reusable layout templates. Old annotations are remapped when panel counts match.

Compare multiple languages

Side-by-side or overlay views, per-language masks, wheel zoom and pan, plus page / panel / anchor / grid alignment with reusable presets.

Notes that travel

Markdown notes at page or panel scope, tags, sources, a scratch pad, full-text search and one-click "copy context" for pasting into an LLM.

Portable output

Export HTML with an image folder or as a single embedded file, render page / panel / collage PNGs, and move everything as a `.mnproj` project.

What is KomaYomi? ​

KomaYomi — Manga Learner — is a local web application for learning languages with manga: read the same pages in Japanese, Chinese and English, align them precisely, and take notes. Your page images stay in a raw/ folder; every panel, note, tag, alignment offset and annotation lives in plain JSON under data/. Nothing leaves the machine unless you export it.

It is designed for study and translation review rather than for hosting copyrighted material: bring your own scans, point the app at the folder, and work page by page.

Status at a glance ​

KomaYomi is at 0.1.0 and under active development. The documentation distinguishes what exists today from what is planned.

Working today — library scanning, XY-cut panel detection, manual panel editing, panel grouping and page history, panel/layout templates, vector annotations (rectangle, ellipse, arrow, text), compare reader with masks and four alignment modes, Markdown notes with search, HTML / PNG / PDF (print) / Word export, backup ZIP plus upload to a WebDAV/network target, a WebDAV/network image source with on-demand LRU caching and an offline write queue, `.mnproj` project export/import, CLI batch tools.
Planned — vocabulary-list export; scheduled backups; a native mobile app; broader integration tests.

Anything marked Planned in this site is not implemented yet. If a page describes behavior that is not in the code, treat this note as authoritative and the feature as unavailable.
