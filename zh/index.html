分格优先

自动 XY-cut 检测，并支持手动绘制、合并、编号和可复用的布局模板。分格数量一致时，原有标注会重新映射。

多语言对照

并排或叠加视图，按语言独立遮罩，滚轮缩放与平移，以及页面 / 分格 / 锚点 / 网格四种对齐方式，可保存为预设。

笔记随身走

页面级或分格级的 Markdown 笔记、标签、来源、速记板、全文搜索，以及一键“复制上下文”粘贴到 LLM。

可移植的输出

导出带图片文件夹的 HTML 或单文件内嵌 HTML，渲染页面 / 分格 / 拼图 PNG，并用 `.mnproj` 项目迁移全部内容。

什么是 KomaYomi？ ​

KomaYomi（Manga Learner）是一个用漫画学语言、做笔记的本地 Web 应用：同一部漫画的日文、中文和英文版本并排对照，边读边记。你的页面图片保留在 raw/ 文件夹中；每个分格、笔记、标签、对齐偏移和标注都存放在 data/ 下的纯 JSON 里。除非你主动导出，否则任何内容都不会离开本机。

它的定位是学习与翻译校对，而不是托管受版权保护的内容：自备扫描件，把应用指向该文件夹，然后逐页处理。

状态一览 ​

KomaYomi 目前处于 0.1.0 版本，正在积极开发中。本文档会区分已经实现的功能和计划中的功能。

当前可用 —— 图库扫描、XY-cut 分格检测、手动编辑分格、分格分组与页面历史、分格/布局模板、矢量标注（矩形、椭圆、箭头、文本）、带遮罩和四种对齐模式的对照阅读、可搜索的 Markdown 笔记、HTML / PNG / PDF（打印）/ Word 导出、备份 ZIP 及上传到 WebDAV/网络目标、带按需 LRU 缓存和离线写入队列的 WebDAV/网络图片源、`.mnproj` 项目导出/导入、CLI 批处理工具。
计划中 —— 词表导出；定时备份；原生移动端应用；更广泛的集成测试。

本站中标记为 计划中 的任何内容都尚未实现。如果某个页面描述了代码中并不存在的行为，请以本条说明为准，并视该功能为不可用。
