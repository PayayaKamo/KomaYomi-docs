数据格式 ​

KomaYomi 存储的一切都是纯 JSON 或纯图片文件。本页记录磁盘上的约定，便于你写脚本、做 diff 或手工修复。

文件映射 ​

路径内容
raw/<volume>/<language>/<chapter>/*.jpg页面图片（输入，永远不会被修改）。
data/pages/<volume>/<chapter>/<index>.json每页一个页面文档（index 从 0 开始）。
data/templates/panel.json已保存的分格模板。
data/templates/export.json已保存的导出模板。
data/presets/align.json已保存的对齐预设。
data/layouts/<id>.json声明式布局模板。
data/library.json手动指定的语言目录映射。
data/cache/thumbs/缩略图缓存（可以安全删除）。
data/backups/导入的 .mnproj 文件的副本。
exports/生成的 HTML、PNG、备份 ZIP 和项目文件。

写入是原子性的：服务器先写入 <file>.tmp，再重命名覆盖目标文件。即使崩溃，旧文件也会保持完整。

字段参考 ​

字段类型说明
version1页面文档的 schema 版本。
volume、chapterstring必须与文件夹名一致。
pageIndexnumber从 0 开始。
panelsPanel[]见下文。坐标会被限制在 0..1；宽高至少为 0.005。
notesNote[]scope 为 page 或 panel；分格笔记必须带 panelId。没有字符串 text 的记录会被丢弃。
offsetsRecord<Lang, AlignOffset>页面级对齐。scale 被限制在 0.2..4。
alignModepage | panel | anchors | grid无效值会变成 page。
panelOffsetsRecord<panelId, Record<Lang, AlignOffset>>分格级对齐。
gridStepnumber百分比，限制在 0.1..10，默认 1。
readingDirectionrtl | ltr | ttb无效值会变成 rtl。
detectorVersionstring例如 xycut-1.3、layout:<id>、plugin:<name>。
detectedAtISO string最后一次检测的时间。
detectSourceauto | template | plugin | manual分格是由哪条路径产生的。
editCountnumber每次写入都会递增。不是审计日志。
lastEditedAt、lastEditSummarystring人类可读的变更摘要。
groupsPanelGroup[]读取时会移除悬空的分格 id；空分组会被丢弃。
annotationsAnnotation[]无效的点会被丢弃。
annotationsVisibleboolean为 false 时在界面和导出中隐藏标注图层；数据仍然保留。
updatedAtISO string写入时由服务器设置。

分格（Panel） ​

json
{
  "id": "p1",
  "rect": { "x": 0.04, "y": 0.03, "w": 0.44, "h": 0.31 },
  "source": "auto",
  "number": 1
}
  • id 在页面内局部有效，且必须唯一。
  • x、y、w、h 以页面为基准归一化。
  • source 为 auto、manual 或 merged。
  • number 是可选的；省略时使用阅读顺序。

笔记（Note） ​

字段类型说明
idstring在页面内唯一。
scopepage | panel
panelIdstring | null分格范围时必填。
textstringMarkdown。原始 HTML 会被转义。
tagsstring[]
source{ title?, url?, text? }text 是自由形式的来源标签。
images{ id, name, dataUrl }[]笔记附带的截图。可在笔记编辑器中粘贴、拖入或添加；超过 400 KB 的图片会缩小到长边 1600 px。
createdAt、updatedAtISO string

标注类型 ​

arrow、rect、ellipse、highlight、text、badge、mosaic、pen。

坐标相对于标注的作用范围（页面框或分格框）。自由画笔使用完整的 points 折线；箭头使用首尾两个点。

版本规则 ​

页面文档 ​

  • version 目前为 1。
  • 读取时，服务器会规范化而不是拒绝：未知字段被丢弃，无效数字变为默认值，矩形被限制范围，悬空的分组引用被移除，缺失的 id 会被生成。
  • 无法解析的页面 JSON 会被视为不存在；应用随后会自动检测并重新创建它。
  • 将来出现 schema 变更时，也会用同样的规范化方式在读取时迁移旧文件。不要假设未知的将来字段会被保留。

项目包 ​

  • schemaVersion 目前为 1。
  • 声明了更高版本的项目包会被拒绝，并给出明确错误：请先升级应用。
  • 版本 0 的项目包（早期实验）会在导入时迁移：顶层的 images、file 字段和扁平的 langDirs 映射会被转换为当前的 manifest 结构。
  • 缺失的可选字段会用默认值填充；无效的图片会被丢弃，而不是中止导入。

项目包（.mnproj） ​

.mnproj 文件是一个 ZIP：

text
manifest.json
pages/<volume>/<chapter>/<index>.json
templates/...
presets/...
config/library.json          (optional)
assets/<sha1>.<ext>          (packaged mode only)

清单（Manifest） ​

json
{
  "schemaVersion": 1,
  "appVersion": "0.1.0",
  "createdAt": "2026-05-12T10:00:00.000Z",
  "updatedAt": "2026-05-12T10:00:00.000Z",
  "storageMode": "reference",
  "name": "点兔第14卷 学习笔记",
  "language": {
    "volumes": { "点兔第14卷": { "ja": "raw-ja", "zh": "raw-zh" } },
    "resolved": { "点兔第14卷": { "ja": "raw-ja", "zh": "raw-zh" } }
  },
  "inventory": {
    "volumes": [
      {
        "volume": "点兔第14卷",
        "languages": ["ja", "zh"],
        "langDirs": { "ja": "raw-ja", "zh": "raw-zh" },
        "chapters": [{ "chapter": "172", "pages": 18, "images": 36 }]
      }
    ],
    "pageCount": 18,
    "images": [
      {
        "volume": "点兔第14卷",
        "chapter": "172",
        "pageIndex": 0,
        "lang": "ja",
        "name": "001.jpg",
        "sha1": "…",
        "size": 245678,
        "path": "raw/点兔第14卷/raw-ja/172/001.jpg"
      }
    ]
  },
  "notes": { "pages": 18, "noteCount": 42, "annotationCount": 0, "text": "optional user memo" }
}

存储模式 ​

模式图片大小可移植性
reference清单中只有路径 + SHA-1。小。需要原始图片。支持按 SHA-1 或文件名重新关联文件夹。
packaged去重后放入 assets/<sha1>.<ext>。大。自包含；导入时会把图片写入 raw/。

导入会逐文件检查冲突，并提供覆盖、合并或跳过：

  • 合并会在传入页面缺少分格/标注时保留已有的分格/标注，按 id 合并笔记（同一 id 以传入的为准），并且从不会删除已有笔记。
  • 任何导入之前都会写入 data/ 的快照；原始项目包也会保留在 data/backups/projects/ 下。

布局模板 ​

路径：data/layouts/<id>.json

json
{
  "id": "layout-1712345678901",
  "name": "四格等分",
  "scope": "page",
  "volume": "点兔第14卷",
  "chapter": "172",
  "pageIndex": 3,
  "readingDirection": "rtl",
  "margin": { "top": 0.02, "right": 0.02, "bottom": 0.02, "left": 0.02 },
  "gap": 0.012,
  "colWeights": [1, 1],
  "grid": {
    "cols": 2,
    "rows": [
      { "height": 1, "cells": [{}, {}] },
      { "height": 1, "cells": [{}, {}] }
    ]
  },
  "pageOverrides": {
    "2": { "gap": 0.02 }
  },
  "createdAt": "2026-05-12T10:00:00.000Z",
  "notes": "用于第172话大部分页面"
}
  • scope 为 page、chapter 或 volume；解析时优先选择最窄的匹配。
  • cells[].span 允许一个单元格跨多列。
  • row.height 是相对权重。
  • pageOverrides 的键是从 1 开始的页码。
  • margin 和 gap 是比例；colWeights 默认等宽。

对齐预设：

json

导出模板 ​

路径：data/templates/export.json

一个由具名模板组成的数组，每个模板存储导出配置的一部分：

json
[
  {
    "id": "exp-…",
    "name": "左图右注-紧凑",
    "createdAt": "2026-05-12T10:00:00.000Z",
    "config": {
      "template": "two-column",
      "languages": ["ja", "zh"],
      "embedImages": false,
      "pageWidthRatio": 46,
      "columnGap": 28,
      "fontScale": 1,
      "columns": 1
    }
  }
]

完整的导出配置还包括 title、volume、chapter、pageIndices、offsets、showPanelBoxes、includeNotes、onlyWithNotes 和 noteFilterTags。

备份 ZIP ​

备份是一个 ZIP，其中每个条目都以 data/ 为前缀：

text
data/pages/...
data/templates/...
data/presets/...
data/library.json
data/.backup-meta.json

缩略图缓存（data/cache/）以及 .tmp / .log 文件会被排除。恢复会覆盖 data/ 下的同名文件，但不会删除备份中不存在的页面；恢复前会先写入当前数据的快照。

data/library.json ​

json
{
  "volumes": {
    "点兔第14卷": {
      "dirs": { "ja": "raw-ja", "zh": "raw-zh" }
    }
  }
}

这里只存放手动覆盖项。没有条目的卷仍会进行自动语言识别。
