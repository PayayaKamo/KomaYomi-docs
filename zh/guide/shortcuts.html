键盘快捷键 ​

一页汇总所有按键和鼠标手势。焦点在文本输入框内时，单键快捷键会被忽略，因此写笔记不会写到一半突然换视图。

这一页解决什么问题 ​

快捷键分散在图库、切格工作台、对照阅读和笔记编辑器里。与其在各个视图里到处翻找，不如把这一页放在手边，或者打印出来贴在显示器旁边。

全局 ​

按键操作
[上一页（可跨话）。
]下一页（可跨话）。
P切换到切格工作台。
C切换到对照阅读。
S显示或隐藏图库侧栏。
N显示或隐藏笔记栏。
E打开导出对话框（有打开的页面时）。
?打开快捷键与操作帮助。
Ctrl+Z撤销上一步分格改动。
Ctrl+Shift+Z重做。
Ctrl+Y重做（另一种）。

文件 ​

按键操作
Ctrl+O打开工程文件（.mnproj）。
Ctrl+S保存当前页。
Ctrl+Shift+S另存为工程。

这些文件快捷键在输入时也有效，与桌面应用一致。

切格工作台 ​

按键 / 手势操作
拖动框体移动分格。
拖动角点或边缘手柄八向缩放。
双击空白处添加一个默认分格。
在空白处拖拽框选一个分格。
Shift + 拖拽把新分格约束为正方形。
Alt + 拖拽关闭吸附。
Ctrl 点击 / Shift 点击把分格加入或移出选择。
方向键按页面 0.2% 微调选中项。
Shift + 方向键按 1% 微调。
Delete / Backspace删除选中的分格（或选中的标注）。
Enter保存（确认模式）。
Esc放弃改动（确认模式）；否则退出标注工具或取消选中标注。

标注工具栏没有字母快捷键，只能用鼠标。Esc 总是后退一级：选中标注 → 当前工具 → 有未保存改动的页面。

对照阅读 ​

按键 / 手势操作
H全部遮蔽（打开遮蔽总开关）。
Shift+H全部显示（关闭遮蔽总开关）。
拖动某一栏平移该语言。
在某栏上滚轮缩放该语言。
Alt + 拖拽 / 滚轮只对当前格应用该手势。
点击已遮蔽的栏临时显示；再次点击可重新遮蔽。

分格导航使用 上一格 / 下一格 按钮；它们没有绑定按键，因为 [ 和 ] 已经用于翻页。

笔记编辑器 ​

按键操作
Ctrl+B加粗。
Ctrl+I斜体。
Ctrl+K插入链接。
Ctrl+Enter保存笔记（或保存随手记）。
标签框里按 Enter添加标签。
Tab在编辑器内缩进。

仅鼠标操作 ​

有些控件按设计没有键盘等价操作：

  • 分隔条：拖动调整大小，双击恢复默认。
  • 对照阅读中的语言标签排序：拖动标签。
  • 缩放按钮：分格工具栏中的 − / ＋。
  • 分格模板与对齐预设选择器。

常见坑 ​

  • 快捷键却打出了字母。 焦点在 input、textarea 或 contenteditable 元素中。先点击舞台。
  • H 不遮蔽。 焦点在笔记或工具栏输入框中；输入时对照快捷键会被忽略。
  • E 没反应。 没有打开的页面，导出对话框不可用。
  • Ctrl+Z 撤销的是笔记。 在文本字段内用的是浏览器原生撤销；页面级撤销只在舞台上有效。
