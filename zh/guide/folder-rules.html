目录识别规则 ​

目录识别规则用来描述卷、语言、话和页面分别位于路径的哪一层。它专门伺候那些不肯乖乖排成默认 raw/<卷>/<语言>/<话>/<页面> 的图库。

这一步解决什么问题 ​

真实的收藏很少整齐划一：有的系列多一层作者目录，有的出版社把语言放在最后，只有一种语言的合集干脆没有语言文件夹。为此重命名上千个文件是下策。规则让你直接描述现有的目录形状，而不必迁就默认结构。

使用对话框 ​

  1. 在图库侧栏底部打开目录识别规则…。
  2. 编辑 JSON 规则数组。＋ 插入示例规则会给一个起点；填入默认规则可以恢复内置结构。
  3. 在只预览子目录里填一个子文件夹，只测试一个分支；留空则扫描整个 raw/。
  4. 检查匹配 n 个文件 · m 卷、未识别文件列表，以及每话下列出的页面。
  5. 点击保存规则，图库会按新规则重新扫描。

预览会随输入实时更新。恢复默认会丢弃你的修改；只有保存规则才会真正改变图库。

占位符 ​

占位符别名含义
{series}{seriesName}、{work}卷之上的系列层；只有确实存在这一层时才写。
{volume}{vol}、{book}侧栏里显示的卷。
{chapter}{chap}、{ch}、{episode}话文件夹。
{language}{lang}、{locale}能识别为语言的文件夹：内置别名（如 ja、zh-cn），或在卷设置里映射过的目录。
{page}{file}、{image}、{img}图片文件。每条规则都必须有。

所有平台上的匹配都不区分大小写，所以从 Windows 上抄来的规则换到别的系统仍然能用。

可选段与通配符 ​

写法行为
{chapter}?这一段可以不存在。{volume}/{language}/{chapter}?/{page} 同时匹配有话目录和没有话目录的情况。
* 或 **只匹配一个你不关心的路径段。两种写法行为相同。
普通文字必须与文件夹名完全一致，例如 manga/{volume}/… 里的 manga。

规则必须包含 {page}。除非规则里写了回退的 language，否则也必须包含 {language}。

一条规则的结构 ​

json
[
  {
    "id": "series-volume-language-chapter-page",
    "name": "系列 / 卷 / 语言 / 话 / 页面",
    "pattern": "{series}/{volume}/{language}/{chapter}?/{page}",
    "ignore": ["_extras", "covers"],
    "extensions": [".jpg", ".jpeg", ".png"]
  },
  {
    "id": "flat-japanese",
    "name": "扁平目录，仅日文",
    "pattern": "{volume}/{chapter}/{page}",
    "language": "ja"
  }
]
字段必填含义
id否稳定标识，省略时自动生成；重复的 id 会被拒绝。
name否对话框里显示的名称。
pattern是用斜杠分隔、含占位符的路径。
ignore否永不进入的文件夹名。
extensions否接受的文件扩展名，可带或不带前导点；默认 .jpg、.jpeg、.png、.webp、.gif、.avif、.bmp。
language否没有 {language} 时的回退语言；写语言 id，例如 ja、zh、en。
enabled否设为 false 可保留规则但不启用。

顺序、语言与冲突 ​

  • 规则按顺序尝试，第一条匹配的生效。最具体的规则要放在前面。
  • {language} 段里的文件夹名仍会按别名识别，例如 ja、jp、日本語、zh-cn、cn、english，或在卷设置里映射过的目录。见图库与导入。
  • 没有 {language} 段时，该规则匹配到的页面都使用规则里的 language。
  • 不匹配任何已启用规则的文件会出现在未识别列表里，不会进入图库。
  • 规则只影响识别，绝不会重命名、移动、复制或转换文件。

什么时候会破坏已有工作 ​

页面数据保存在 data/pages/<卷>/<话>/<序号>.json。修改规则可能改变识别出的卷 ID 或话 ID，已有的分格和笔记不会自动跟过去。新收藏请在标注之前应用规则；如果之后必须改，先做一份备份，再抽查几页。

常见坑 ​

  • 预览是空的。 规则从扫描根目录开始整段匹配。把每一层都写进去，包括 manga/ 这种固定目录。
  • 有些话缺少必需的路径段。 用 ? 把它标成可选，或者为更扁平的结构再加一条规则。
  • 所有页面都进了同一话。 少了 {chapter} 占位符，或者它被通配符顶掉了。
  • 某种语言没被识别。 文件夹别名不认识；在卷设置里映射，或者给规则加 language 回退。
  • 保存后卷列表变了。 这是重新扫描的预期结果。写笔记前先看未识别列表。
  • 两条规则同时匹配。 第一条生效。把更具体的规则拖到前面。
