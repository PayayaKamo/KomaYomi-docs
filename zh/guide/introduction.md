# 简介

KomaYomi —— **Manga Learner** —— 是一个本地优先的 Web 应用，用漫画学语言。你把同一份页面保留为日语、中文和英语三个版本，把页面切成一个个分格，并排阅读这些分格，再写下 Markdown 笔记；笔记始终挂在它所描述的那个分格上。

它不是用来随意翻阅的漫画阅读器，也不是分发平台。一切都在你自己的机器上运行，读取你自己的图片文件夹。

## 它解决什么问题

翻译最好按分格逐格研读，而不是按整页。但同一本书三种语言的扫描件很少能对齐：整页会偏移，分格的裁切范围不同，文字位置也各有出入。普通图片查看器只提供一个缩放级别，没有笔记，也无法表达“这个对话框，在这三个版本里”。

KomaYomi 补上了中间缺失的一层：

1. **结构** —— 分格会被检测出来，并以归一化矩形保存，因此无论缩放级别或导出尺寸如何变化都不会失效。
2. **对齐** —— 每种语言都可以独立微调，让同一个分格真正重叠。
3. **笔记** —— 每条记录都限定在某一页或某个分格，使用 Markdown，并支持标签和来源。

## 五步工作流

| 步骤 | 你要做什么 | 页面 |
| --- | --- | --- |
| 1 | 把图片按 `raw/<volume>/<language>/<chapter>/01.jpg` 摆好，或添加已有文件夹。 | [图库与导入](/zh/guide/gallery) |
| 2 | 打开页面，让应用自动切格，再手动修正框。 | [切格工作台](/zh/guide/panels) |
| 3 | 并排或叠加阅读 2–3 种语言，对齐画面，遮住正在自测的语言。 | [对照阅读](/zh/guide/compare) |
| 4 | 写下整页笔记与格级笔记，带标签、来源和截图。 | [笔记](/zh/guide/notes) |
| 5 | 导出学习用 HTML、用于幻灯片的 PNG，或带到另一台机器的工程包。 | [导出](/zh/guide/export) |

窗口有五个始终不变的区域：

- **顶栏** —— 品牌（返回图库）、卷 / 话 / 页、`‹` `›` 翻页箭头、保存指示器、**分格 / 对照阅读** 切换、阅读方向选择器、界面主题、界面语言、**笔记** 与 **导出**。
- **图库侧栏**（`S`）—— 卷 → 话 → 页，带逐页警告，以及添加漫画、目录规则、工程文件、交换文件和备份的入口。
- **舞台** —— 切格工作台或对照阅读，取决于视图切换。
- **笔记栏**（`N`）—— 整页笔记、格级笔记、总览搜索和随手记暂存。
- **分隔条** —— 拖动图库与舞台之间、或舞台与笔记之间的竖向手柄调整宽度；双击恢复默认。

一页可以有一种、两种或三种语言。对照阅读中的语言标签只对当前页实际存在的语言启用。

## 最初的十分钟

1. 启动应用（`npm run dev` 或桌面版），打开 `http://127.0.0.1:5173`。
2. 在 `raw/` 下放一卷，或点击侧栏的 **＋ 添加漫画**，指向已有文件夹。
3. 点击侧栏中的某一页。首次打开会自动检测分格，并把结果保存到 `data/pages/`。
4. 切换到 **对照阅读**（`C`），勾选 `JA` 和 `ZH`，拖动某一栏直到分格对齐。
5. 打开 **笔记**（`N`），选中一个分格，写下第一条笔记。按 `Ctrl+Enter` 保存。
6. 按 `E` 导出 HTML 文件，在浏览器中打开。

## 常见坑

- **图库里什么都没有。** 侧边栏只扫描 `raw/`；先添加文件夹或挂载远端目录。参见[图库与导入](/zh/guide/gallery)。
- **第一页分格是错的。** 自动检测只是草稿，不是结论。先修框再写格级笔记；之后重新检测会丢弃手动修改。
- **某个语言标签是灰的。** 这一页在该语言下没有图片。检查页数是否一致、卷的语言映射是否正确。
- **换机器后笔记好像没了。** 笔记在 `data/`，图片在 `raw/`；两者都要带走，或者导出 `.mnproj`。参见[工程文件与格式](/zh/guide/project-files)。
- **离线时图片请求失败。** 只有离线前打开过的页面在缓存里。参见[备份与远端](/zh/guide/remote)。
