简介 ​

KomaYomi（格读）是一个本地优先的网页应用，用来把同一页漫画的几种语言放在一起读。常见的情形是三个窗口——原版、译本、词典——外加一个永远和页面对不上的笔记软件。KomaYomi 先把页面切成格，把同一格在日文、中文、英文之间对齐，再让你把 Markdown 笔记和标注钉在具体的那一格、具体的那一点：翻译吐槽、用词考据、生词、校对疑问，都能落在原处。学日语时顺手对照熟肉、做汉化校对时拿生肉核原文、或者单纯想知道这句台词在各版里分别怎么翻，都用得上。

它既不是随手翻漫画的阅读器，也不是分发平台。所有东西都跑在你自己机器上，只读你自己的图片文件夹。

已经装好了？直接跳到最初十分钟。从零开始？安装与运行里有桌面安装包、npm run dev、Docker、PWA 等全部路径。

作者主页：X · @payayakamo · note · @payayakamo。这两个是作者个人主页，不是产品官网。

它解决什么问题 ​

学翻译，按分格逐格看比按整页啃有效得多。可同一本书的三份扫描件很少乖乖对齐：整页偏移、分格裁切不同、文字位置各有各的想法。普通看图软件只有一个缩放级别，没有笔记，也没法表达「这个对话框，在这三个版本里分别长啥样」。

KomaYomi 补的就是中间缺的那一层：

  1. 结构 —— 分格检测后以归一化矩形保存，缩放、改窗口、换导出尺寸都不会把框弄丢。
  2. 对齐 —— 每种语言都能单独微调，直到同一格真正重叠。对，终于能重叠。
  3. 笔记 —— 每条记录都挂在某一页或某一格上，Markdown 写，带标签和来源。「先记在心里」从此不算计划。

五步工作流 ​

步骤你要做什么页面
1把生肉、熟肉整理成 raw/<volume>/<language>/<chapter>/01.jpg，或者直接指向已有的文件夹。预处理与重命名、图库与导入
2打开页面，让它自动切格，再手动修框。自动检测只是草稿，不是结论。切格工作台
3并排或叠加阅读 2–3 种语言，对齐画面，遮住正在自测的那一版。对照阅读
4写下整页笔记与格级笔记，带标签、来源和截图。翻译吐槽尤其欢迎。笔记
5导出学习用 HTML、用于幻灯片的 PNG，或带到另一台机器的工程包。导出

界面一览 ​

窗口有五个始终不变的区域，用熟了基本可以闭眼操作：

  • 顶栏 —— 品牌（返回图库）、卷 / 话 / 页、‹ › 翻页箭头、保存指示器、编辑 / 阅读 使用模式、分格 / 对照阅读 / 原版阅读 切换、阅读方向选择器、专注模式（⛶）、帮助（?）、设置（⚙，仅编辑模式）、关于（ⓘ）、界面主题、界面语言、笔记 与 导出。
  • 图库侧栏（S）—— 卷 → 话 → 页，带逐页警告，以及添加漫画、目录规则、工程文件、交换文件和备份的入口。
  • 舞台 —— 切格工作台、对照阅读或原版阅读，取决于视图切换。
  • 笔记栏（N）—— 整页笔记、格级笔记、总览搜索和随手记暂存。
  • 分隔条 —— 拖动图库与舞台之间、或舞台与笔记之间的竖向手柄调整宽度；双击恢复默认。

一页可以挂任意数量的语言。对照阅读里的语言标签只对当前页实际存在的语言亮起。

窗口变窄时，顶栏和切格工作台工具栏不会硬挤：放不下的次要操作会收进 ≡ 溢出菜单，窄到手机宽度时只保留翻页、视图切换这类必要项。菜单里的项目和宽屏时的按钮完全一样，入口没有消失。

起始页 ​

还没有打开图库时，应用会显示起始页。这里有四个入口——导入图片 / 扫描文件夹、新建库、打开 .mnproj、使用指南——并把首次使用的六个步骤排成卡片：导入扫描件、新建库或打开工程、选一页、切格、对照语言，最后批注并导出。

宽屏时卡片排成 3×2，中屏 2×3，窄屏单列。只读模式下导入和新建库入口会隐藏，只保留打开工程和使用指南。

编辑模式与阅读模式 ​

顶栏中央的 编辑 / 阅读 切换决定这个工作区是工作台还是查看器。选择保存在浏览器本地，刷新或重新打开后保持。

  • 编辑模式：可以切格、标注、写笔记、修改阅读方向，改动按保存模式写入 data/；第一次打开的页面会自动切格。
  • 阅读模式：切过去时会先保存当前页尚未落盘的改动，然后清空分格选择、关闭历史与设置对话框，顶栏出现 只读 徽标。适合把成品拿给别人看，或复习时避免误改。

阅读模式下被关闭的操作：

区域阅读模式下的行为
切格工作台切格与编辑工具栏、保存 / 历史、网格与模板、标注绘制工具、键盘微调全部隐藏或失效；只能缩放、平移查看。
对照阅读标注绘制工具隐藏，已有标注照常显示；对齐预设、锚点输入等会写数据的控件隐藏。拖动和滚轮仍可临时平移 / 缩放，但不会写回页面。
笔记栏只能查看和搜索，顶部提示「阅读模式下只能查看笔记」；新建、编辑、删除和随手记都不可用。
图库侧栏隐藏添加漫画、卷设置齿轮、预处理、插件、目录规则和备份；保留工程文件、最近页面与刷新。
顶栏与文件菜单阅读方向选择器禁用；文件菜单只保留打开工程、最近页面和导出；Ctrl+S 不会保存。

这些限制不只是把界面藏起来：阅读模式下浏览器发出的写请求会被服务端统一拒绝（错误码 ERR_READ_ONLY），导出、预览和工程检查仍然可用。

专注模式 ​

专注模式（顶栏的 ⛶，或按 R）是另一件事：它只把顶栏、舞台工具栏、分格分区栏和状态栏暂时收起，让画面占满窗口，不改变编辑 / 阅读模式。按 Esc 或再按 R 退出，触屏设备双击空白处退出。进入时会短暂提示退出方式，提示会自动消失，不会常驻遮挡画面。

最初的十分钟 ​

  1. 先把应用跑起来：开发时执行 npm run dev，装了桌面版就直接打开，然后在浏览器访问 http://127.0.0.1:5173。
  2. 让图库认出你的漫画：把这一卷放进 raw/ 目录，或者点侧栏的 ＋ 添加漫画，选一个已有的文件夹。
  3. 在侧栏点开任意一页。第一次打开会自动切格，结果保存在 data/pages/。
  4. 想两种语言对着看，就切到 对照阅读（C），勾上 JA 和 ZH，拖动其中一栏，让同一格的上下对得齐。一格一格对，比整页来回调省力。
  5. 读到想记的地方，打开 笔记（N），选中一个分格，写下第一条笔记，Ctrl+Enter 保存。
  6. 最后按 E 导出 HTML，用浏览器打开，看看分格和笔记排在一起是什么样。

已实现的功能 ​

图库 —— 扫描卷目录，支持同一根目录下并列多部作品，识别语言目录别名，按排序位置配对页面，并对缺页和命名不一致给出警告；侧栏页面可按双列缩略图、单列缩略图或带语言与笔记数的列表显示，选择按浏览器记住。
分格 —— 自动 XY-cut 检测，新增 / 移动 / 八向缩放 / 合并 / 分组 / 拆分 / 删除，带 1–10 快捷位置与右键移动的手工重排编号，百分比输入，网格生成器，分格模板，声明式布局，插件，跨会话页面历史。
标注 —— 箭头、矩形、椭圆、荧光笔、自由笔迹、文字、编号圆标和马赛克，可放置锚点并绘制引出线，页面级显示开关，按语言隔离，支持右键菜单（删除、改色、复制到其他语言），支持 PNG 导出。
对照 —— 2–3 种语言，并排或叠加，按语言模糊 / 色块遮蔽，滚轮缩放，平移，整页 / 逐格 / 锚点 / 网格对齐，已保存的预设，自定义语言顺序；另有第三种原版阅读视图（缩放与平移可联动 / 独立）、从窗格右键菜单打开的 1:1 放大看图、跨页跨话的上一格 / 下一格并自动居中，以及按分格 ID 深链的分格详情视图。双击对照阅读的任意一行（语言列、行头或空白边距）即可打开该格；详情页可以拖动画面对齐、布局可选并排或堆叠、语言栏可选横排或纵排，对齐仅在当前会话生效。
笔记 —— 整页 / 格级笔记，每页或每格可有多条，带工具栏和实时预览的 Markdown，编辑已有笔记时复用同一个编辑器，标签，来源，附图，总览搜索，复制给大模型，随手记暂存，以及笔记类型：背景知识 / 生词 / 吐槽、每种启用语言一个类型，自定义类型存于 `data/library.json`。类型化卡片在所有出现位置统一为「8% 类型色底 + 3px 色条 + 类型徽标」，深浅主题都清晰；笔记可钉在画面某一点（同一位置的多条笔记合并成带数量的气泡）。笔记栏按 筛选 → 列表 → 编辑器 排列，支持分组与按类型新建；格子详情页内嵌同一个编辑器。
导出 —— HTML（图片目录或单文件）、PNG（整页、当前格、三语拼图）、分享图（1080×1440 封面、单格、三语对照、长页切条，附 18 张 / 20MB 提示）、经浏览器打印对话框的 PDF、含页图与笔记并默认烘焙标注的 Word（`.docx`）、分格边框叠加、打印样式、导出模板。
历史 —— 顶栏 `↺` 打开操作历史：按时间倒序列出可撤销的编辑并标出当前位置，点击可回到某一步。它与撤销栈是同一份数据，不是第二套日志；只读模式下只显示、不可回退。
模式 —— 编辑 / 阅读双模式，切到阅读时先保存再禁用所有写操作；另有专注模式（`R`）一键收起界面，只保留一个不遮挡画面的翻页 / 翻格胶囊。
存储 —— 本地文件夹、挂载的网络共享和 WebDAV，按需拉取图片、有上限的 LRU 缓存、定时自动备份与缓存管理。页面写入是原子的，保存前做 schema 校验，轮转 `.bak` 副本并持有每页写锁。
可移植性 —— `.mnproj` 工程包在打开后即与图库链接，保存会写回同一个文件；桌面端文件菜单提供 **保存到工程文件** 与 **另存为…**（浏览器里回退为下载），另有 `.mntpl` / `.mnexp` / `.mnpage.json` 交换文件、备份与恢复 ZIP、带版本的 schema（页面文档为 4，工程清单为 2）。

尚未实现的功能 ​

以下内容在出现的位置都标记为 计划中：

  • 词表导出。PDF 与 Word 分别用导出对话框里的 PDF（打印） 和 Word 文档。
  • 应用内的图片格式转换。重命名与拆分已包含在预处理里；格式转换仍需在应用之外完成。
  • 更广泛的导入 / 导出往返自动化集成测试。

另有独立的原生移动端应用 KomaYomi-mobile，支持 Android 与 iOS，鸿蒙 NEXT 目前是占位状态。它能打开 .mnproj 工程；0.2.1 版本改为由原生代码解包，导入大工程时不再卡住界面。

亮色与暗色 ​

界面主题默认跟随系统，也可以在顶栏固定为亮色或暗色。导出的 HTML 只有亮色，以保证截图和打印结果一致。

常见坑 ​

  • 图库里什么都没有。 侧边栏只扫描 raw/；先添加文件夹或挂载远端目录。参见图库与导入。
  • 第一页分格是错的。 自动检测只是草稿，不是结论。先修框再写格级笔记；之后重新检测会丢弃手动修改。
  • 某个语言标签是灰的。 这一页在该语言下没有图片。检查页数是否一致、卷的语言映射是否正确。
  • 换机器后笔记好像没了。 笔记在 data/，图片在 raw/；两者都要带走，或者导出 .mnproj。参见工程文件与格式。
  • 离线时图片请求失败。 只有离线前打开过的页面在缓存里。参见备份与远端。
