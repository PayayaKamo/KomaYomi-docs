预处理与重命名 ​

KomaYomi 直接在你现有的图片文件夹里读取，不会复制或转换任何文件；只有你在预处理对话框里主动操作时，才会真实改名或拆分图片。也就是说，把一卷漫画加进图库前花的那几分钟整理，直接决定切格、配对和对照阅读顺不顺。有点麻烦，但总比同一页在三种语言里各返工一遍划算。

这一步解决什么问题 ​

自动切格偏爱干净的书页扫描。页面转倒了、扫描仪黑边还在、混着一堆 AVIF/HEIC、某个版本少了一页——图库照样能打开，但后面的每一步（配对、对齐、笔记、导出）都会继承这些毛病。在源头修一次就好。

KomaYomi 会怎样处理你的文件 ​

行为后果
图片从你指定的文件夹就地读取。不会导入或复制，所有编辑都只写进 data/；只有使用预处理对话框时才会改名或拆分。
页面按排序位置配对，而不是按文件名。改名会改变顺序。中间插入一页，后面的每一页都会顺延。
排序是自然排序：连续数字按数值比较。即使不补零，2.jpg 也会排在 10.jpg 前面。
WebP 已支持检测与拆分；AVIF、HEIC、GIF、BMP 不会解码。依赖自动切格时，请把 AVIF/HEIC/GIF/BMP 转成 JPEG 或 PNG；WebP 可直接检测，拆分输出 PNG。
一个图片文件就是一页。跨页扫描要么保持为一个文件，要么用预处理对每种语言同时拆分。

整理清单 ​

如果原图很珍贵，先复制一份再动手。下面的顺序比用什么工具更重要。

  1. 转正、校正倾斜。 阅读方向是按页保存的，但一张横躺的扫描图，对照阅读救不回来。
  2. 裁掉扫描仪黑边和对页阴影。 页边方正时，贴着边缘的分格更容易被正确检测。
  3. 需要自动切格就把 AVIF/HEIC/GIF/BMP 转成 JPEG 或 PNG。 WebP 页面可以直接用。画质要足够高，保证台词仍然清楚。
  4. 一话一个文件夹。 不要把两话混在同一目录里；话是分格模板、对齐预设和导出的基本单位。
  5. 去掉不是正文页的图，例如封面、版权页、彩插，或另一版根本没有的赠品图。多出一页，后面每一页都会跟着错位。
  6. 跨页要么不拆，要么每版都在同一位置拆。 一张跨页算一页。如果只拆了日文生肉、没拆中文熟肉，日文的第 12 页就会对应中文的第 12–13 页，配对立刻乱掉。用预处理里的**拆分…**可以一次切成所有语言。
  7. 只在确实有帮助时规范文件名。 补零（001.jpg）便于对比和人工检查，但扫描器用的是排序位置和自然排序，1.jpg 与 001.jpg 都能用。预处理里的批量改名会整话重新编号，并同步迁移已保存的页面数据。

在 KomaYomi 里改名与拆分 ​

打开预处理…并选择卷。除了卷/话标题、页序、排除和页面角色，每个话的区块里还有一块磁盘文件，提供两个真实文件操作。图片格式转换仍然不在应用内。

批量改名。 填好文件名前缀、起始编号和位数，点批量改名。应用会按按钮上方的页序（也就是你用箭头调好的顺序）重新编号，并真实改名磁盘文件（001.jpg、002.jpg……保留原扩展名）。话里所有「每一页都有图」的语言会一起改名，所以第 n 页在各语言里仍是同一张画；缺页的语言不动，并在结果里列出。

页面数据、历史、排除项、页面角色和已保存页序都按页序号索引，因此会在同一次操作里搬移并改写指向。应用内改名不会让批注、笔记或分格编辑丢失。改名后会重新载入本卷，请先应用其他改动，未保存的草稿会丢弃。

动手之前会先写一份清单到 data/file-ops/，列出每个旧名和新名。中途任何一步失败，整批都会回滚，清单标记为 rolled-back，目录保持原样。目标文件名若已属于别的文件，会直接报错拒绝，不会覆盖。

拆分页面。 在某一页下方点拆分…，选择左右（跨页）或上下，填写切分位置百分比并确认。图片会切成 <原名>-a 与 <原名>-b，后半部分成为下一页，后面的页依次顺延。这一页存在的所有语言都在同一位置切分，配对不会错位。拆分支持 PNG、JPEG 与 WebP（WebP 输出为 PNG）；GIF、BMP 会被拒绝。原图会先复制到 data/file-ops/ 再从目录移除。

原页的页面文档会按两半裁剪：落在某半上的分格与批注保留在该半并重算坐标，分格笔记跟随分格，页级笔记留在前半页；两半都沿用原页的阅读方向。拆分后请检查两页，尤其是切口穿过分格的情况。

改名与拆分无法在对话框里撤销

恢复上一次应用横幅只回滚 library.json。改名和拆分在界面里是单向操作；需要找回原名或原图时，请使用 data/file-ops/ 下的清单与备份目录。应用外改名仍然不安全：页面数据按页序号索引，文件管理器或命令行的改名不会搬移批注。

开始标注前的确认 ​

  1. 加入这一卷，在侧栏里打开。
  2. 看卷和话那一行的警告。各语言页数不一致 和 文件名与页序不符 这两条，通常说明整理时出了问题。
  3. 如果目录形状特殊，先打开目录识别规则…，用预览确认后再保存；见目录识别规则。
  4. 打开第一页、中间一页和最后一页，确认同一个分格里确实是同一块画面；如果不是，说明页数或跨页处理有问题。
  5. 这时再运行自动切格，开始写笔记。

常见坑 ​

  • 某种语言多了一页。 多半是多了一张封面或版权页。删掉它，或者给其他语言补上对应的一页。
  • 跨页只在一个版本里拆开了。 要么整页保留，要么每个版本都在同一位置拆。
  • AVIF/HEIC 页面自动切格结果很乱。 转成其他格式；检测不会解码 AVIF/HEIC/GIF/BMP。
  • 在应用外改名后笔记跑到了下一页。 页面数据按序号索引，文件管理器/命令行的改名不会搬移它。请用预处理里的批量改名，或在标注前改名。
  • 拆分切口穿过了分格。 把切分位置放在分格之间，或者拆分后分别修正两半的分格；页级笔记按设计留在前半页。
  • 页面看起来没问题，缩略图却格式不一。 缩略图跟随文件内容而不是扩展名，一个其实是 JPEG 的 .png 仍能正常显示，这只是外观问题。
  • 标注之后才重组了文件夹。 识别出的 ID 变了，旧的页面数据就找不到了。目录规则要在标注之前应用。
