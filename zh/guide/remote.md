# 远端存储与备份

图片可以放在另一块磁盘、NAS 共享或 WebDAV 服务器上，而标注仍保存在本地 `data/` 目录。本页说明远端图库的行为、离线时会发生什么，以及备份如何工作。

## 它解决什么问题

漫画库往往远大于你希望应用索引的磁盘，或者本来就在 NAS 上。把几万张图片复制进 `raw/` 很浪费。同时，标注很小，断网时绝不能丢失。

KomaYomi 把两者分开：**图片按需从远端读取，标注写入本地。**

## 配置远端图库

1. 打开侧栏的 **备份 / 恢复**。
2. 在 **远端素材 / 网络存储** 中点击 **添加远端目录**。
3. 填写目标：

| 字段 | 含义 |
| --- | --- |
| **名称** | 对话框中显示的标签。 |
| **类型** | 本机目录、网络盘 / UNC，或 WebDAV。 |
| **目录路径** | 例如 `D:\manga` 或 `\\nas\share\manga`（本机 / 网络）。 |
| **WebDAV 地址**、**用户名**、**密码** | WebDAV 凭据。 |
| **只读** | 把来源标记为只读，应用永远不会写入它。 |

4. 点击 **测试连接**。对话框会报告*在线* / *离线*，以及目标是否只读。
5. 点击 **同步远端目录树**。

### 同步做了什么

应用遍历远端文件夹，在本地镜像（`data/cache/remote/tree/`）中创建**零字节占位文件**。随后正常的图库扫描器和目录规则在该镜像上运行，因此远端卷会像本地卷一样出现在侧栏，分组同样是 卷 → 语言 → 话。

- 只镜像图片扩展名：`.jpg`、`.jpeg`、`.png`、`.webp`、`.gif`、`.avif`、`.bmp`。
- 遍历深度限制为 10 层，文件上限 **20,000 个**；触及上限时会提示“已达文件上限”并停止。
- 无法读取的文件夹会被计数并报告，但不会中断同步。
- 再次同步会替换镜像；标注不受影响。

## 按需加载与缓存

打开页面时：

1. 应用检查本地缓存中是否有原图。
2. 如果缺失，就从远端来源拉取。
3. 字节写入 `data/cache/remote/files/`，按提供方和路径做内容寻址。
4. 缩略图由缓存的原图生成。

没有“下载整个图库”的步骤。只有你真正打开的页面才会被拉取。

| 控件 | 含义 |
| --- | --- |
| **缓存 n MB / 上限 MB（n 个文件）** | 当前缓存用量。 |
| **缓存上限（MB）** | 上限；默认 **512 MB**，可取任意正值，最大 100,000。 |
| **清除图片缓存** | 删除缓存的远端原图和缩略图；可安全使用，之后会重新拉取。 |

缓存超过上限时，会按最近最少使用淘汰文件，直到用量降到上限的 **90%** 以下。

## 离线行为

允许网络消失：

| 情况 | 结果 |
| --- | --- |
| 页面已缓存 | 离线也能正常打开。 |
| 页面未缓存，远端离线 | 图片请求失败，返回 HTTP **503** `ERR_REMOTE_UNAVAILABLE`；界面显示错误而不是卡住。 |
| 未缓存页面的缩略图，远端离线 | HTTP **502** `ERR_THUMB_FETCH_FAILED`。 |
| 标注、笔记、分格 | 始终在本地；图片已缓存的页面可以继续编辑。 |

没有离线**写入**队列：写入始终落到本地 `data/` 目录，而它就在运行应用的机器上。

::: tip 实用的离线用法
离线前先打开你打算学习的页面。原图和缩略图已缓存，它们会保持可读。缓存上限决定你能随身带多少。
:::

## 密码与凭据

- 密码**不会**存储在 `storage.json` 中。
- 它们以 **AES-256-GCM** 加密到 `data/secrets.json.enc`，使用按安装生成的密钥文件 `data/.secret.key`，权限模式为 `0600`。
- 因此复制或同步 `data/` 文件夹不会泄露密码，界面也从不回显密码——密码字段留空即可保留已保存的值。
- 密码**不包含在备份中**。

## 备份目标

同一个对话框会列出 **备份目标**。目标是备份 ZIP 上传的位置：

1. **添加备份目标**，选择本机目录、网络盘或 WebDAV。
2. **备份到此目标** 会把 `data/` 打成 ZIP，上传到该目标下的 `backups/backup-<timestamp>.zip`。
3. 完成后对话框会报告目标、文件名和大小。

任何已配置的来源或目标都可以用 **测试连接** 测试；离线的会被报告出来。

## 手动备份与恢复

- **生成并下载备份** 会生成 `data/` 的 ZIP：页面、模板、预设、版式、`library.json` 和 `.backup-meta.json`。缩略图缓存和临时文件不包含在内。
- **选择备份文件…** 会先检查 ZIP，报告其中包含多少页、笔记、模板和预设，以及涉及哪些卷。
- 恢复会**覆盖 `data/` 下的同名文件**，但不会删除备份中没有的页面。恢复前会先写入当前数据的快照。

文件级约定和确切的存储 JSON 见[远端存储与备份（参考）](/zh/remote-backup)。

## 常见坑

- **远端卷没有出现。** 运行 **同步远端目录树**；图库扫描的是镜像。检查结果中的文件上限和跳过文件夹数量。
- **每一页都返回 503。** 远端离线，且该页从未缓存。重新联网后再次打开页面。
- **磁盘占用持续增长。** 缓存上限默认 512 MB；确有需要再调高，或在切换图库时清除缓存。
- **备份里没有密码。** 这是有意设计；在另一台机器恢复后重新输入密码。
- **网络路径在资源管理器里能用，这里不行。** 网络盘必须对运行应用的账户可见——服务账户或另一个桌面用户时尤其要注意。
