切格工作台 ​

切格工作台是把一页变成结构化数据的地方。自动检测只是起点；工作台是为快速、可逆地修正检测结果而设计的。

它解决什么问题 ​

后续每项功能都依赖分格：对照阅读、格级笔记、PNG 单格导出、HTML 导出。框错了，后面全错。自动检测能处理好大多数页面，但扉页、跨页、边缘窄条和非常规版式总需要人工介入。

工具栏逐项说明 ​

第一行 —— 底图与切分 ​

控件作用说明
底图选择器选择显示哪种语言的画面，并用它做检测。分格矩形由本页所有语言共用，所以这里只改变你画框所依据的图。
检测器标签显示生成当前分格的算法版本，例如 xycut-1.3、layout:<id>、plugin:<name>。旧数据 表示该页 JSON 早于版本记录功能。
状态文本显示分格是自动、按模板、按插件还是手动改过，以及保存次数和最后一次编辑摘要。这是编辑计数器，不是审计日志。
自动切格在底图上运行检测，并替换当前分格。检测进行中或本页没有图片时不可用。重新检测会丢弃手动修改。
添加格子在页面中部附近添加一个默认分格。更快的替代方式：双击空白处。
合并 (n)把选中的分格合并为一个框，source: "merged"。选中两个及以上分格时可用。
删除删除选中的分格以及它们的格级笔记。等同于 Delete / Backspace。

第一行 —— 保存 ​

控件作用
自动改动后约 0.7 秒自动保存。
确认改动保持未保存，直到你点击 ✓ 或按 Enter。× 或 Esc 放弃并回到上次保存。
↶ / ↷撤销 / 重做（Ctrl+Z、Ctrl+Shift+Z、Ctrl+Y）。
✓保存当前页的改动（仅确认模式）。
×放弃未保存的改动（仅确认模式）。
未保存标记确认模式下，页面有未保存改动时出现。
编号显示或隐藏分格序号标记。

保存模式会记在浏览器中。顶栏始终显示当前状态：已保存、保存中…、待保存 或 未保存改动。

第一行 —— 缩放 ​

− / 百分比 / ＋ 控件把舞台缩放从 50% 调到 300%，步进 15%。缩放只影响显示；分格坐标归一化到 0..1，不会改变。

第二行 —— 数值矩形 ​

只选中一个分格时，第二行显示 格子坐标，含四个百分比输入框：

字段含义
X左边缘，占页宽的百分比。
Y上边缘，占页高的百分比。
W宽度，占页宽的百分比。
H高度，占页高的百分比。

输入数值会立即更新分格。保存时，超出页面的数值会被限制回页面内。

第二行 —— 网格生成器 ​

字段范围含义
行1–8行数。
列1–6列数。
间距0–8 %单元格之间的间隙，占页面的百分比。
生成网格—用均匀划分的网格替换当前分格。

固定杂志版式的章节可以用网格；版式完全重复时，用分格模板。

第二行 —— 模板与 JSON ​

分格模板 会记录当前页的矩形：

  1. 打开 分格模板，输入名称，点击 把当前页存为模板。
  2. 选择模板，然后 套用本页 或 套用整话。
  3. 套用到整话时会要求确认，因为已有分格会被覆盖。

新页面的分格数与模板相同时，格级笔记会按阅读顺序重新映射。数量不同时，格级笔记会被丢弃，而不是悄悄挂到错误的分格上；整页笔记始终保留。模板保存在 data/templates/panel.json。

复制 JSON 路径 复制 data/pages/<volume>/<chapter>/<index>.json。支持手工编辑该文件；服务器在读取时会规范化矩形、修复缺失的 id，并丢弃悬空引用。

画布上的鼠标与键盘 ​

操作手势
移动分格拖动框体。
缩放拖动八个手柄之一。
快速添加分格双击空白处。
精确框选分格在空白处拖拽。
约束为正方形拖拽时按住 Shift。
关闭吸附拖拽或绘制时按住 Alt。
取消当前框Esc。
多选Ctrl 点击或 Shift 点击方框。
微调方向键移动选中项 0.2%；Shift + 方向键移动 1%。
删除Delete 或 Backspace。
保存 / 放弃（确认模式）Enter / Esc。

所有坐标都以页面为基准归一化，因此分格在任何缩放级别或导出分辨率下位置都不变。

编号与阅读方向 ​

  • 编号 切换序号标记。
  • 阅读方向按页面存储：rtl（从右到左 · 从上到下）、ltr（从左到右 · 从上到下）或 ttb（从右到左 · 竖排）。在顶栏修改。
  • 分格可以带显式的 number，覆盖自动阅读顺序；否则编号由矩形和阅读方向推导。
  • 同一顺序也驱动对照阅读、笔记总览和 HTML 导出。

先定阅读顺序

开始编辑前如果分格编号看起来不对，先改阅读方向选择器。可以在 JSON 里手工重新编号，但修改方向会一次性修正整话的所有页面。

标注工具 ​

标注图层画在画面之上，与分格分开存储。

控件作用
标注：显示中 / 已隐藏全局可见性。隐藏会保留数据，并在导出中隐藏。
选择与移动选中已有标注；拖动可移动。
箭头从尾部拖到头部。
矩形 / 椭圆拖出方框或椭圆。
荧光笔半透明自由笔迹。
自由笔迹不透明笔迹；保留完整折线。
文字点击后输入文字。
编号圆标点击后输入编号。
马赛克拖出矩形；该区域被像素化。
颜色样块设置新标注的颜色；选中标注时点击样块可为它改色。
删除删除选中的标注。
清空确认后删除本页所有标注。

作用范围跟随选择：选中一个分格时，提示为新标注画在格 N 内；没有选中时，新标注作用于整页。Esc 退出当前工具或取消选中标注。

只有标注图层显示时，导出的 HTML 和 PNG 才包含标注。HTML 导出还有一个 在原图上标出格子边框 选项，它与标注无关。

分组 ​

页面 JSON 有一个 groups 字段（{ id, name, panelIds, number }），读取、写入、导入和导出时都会保留。计划中 目前应用内没有创建或编辑分组的界面，只有直接编辑 JSON 才能改动它们。

安全的修正流程 ​

  1. 打开页面，让自动检测运行。
  2. 修正明显的框：移动、缩放、添加、删除。
  3. 合并跨页大图的分格。
  4. 保存（确认模式下按 ✓）。
  5. 切换到 对照阅读（C），确认同一个分格确实包含同一块画面。

手动改过之后，除非愿意丢失修改，否则不要再运行 自动切格。

常见坑 ​

  • 自动切格替换了我的框。 检测会覆盖。第一次切分成功后，改用分格模板或手工编辑。
  • 页面没有图片。 检测被禁用，舞台显示空状态。补上缺失的语言文件夹，或在卷设置里映射。
  • WebP 页面检测不了。 WebP 可以显示，但不会解码用于检测；请转成 JPEG 或 PNG。
  • 套用模板后格级笔记不见了。 模板的分格数不同，格级笔记被丢弃；整页笔记保留。需要时从备份恢复。
  • “未保存改动”一直不消失。 你处于确认模式。按 ✓ 或 Enter；× 放弃。
  • 标注看不见。 标注图层被隐藏，或分格筛选处于激活状态。检查 标注：显示中。
