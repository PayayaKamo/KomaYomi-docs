图库与导入 ​

图库在每次应用加载时扫描 raw/ 文件夹生成。没有数据库，也没有把扫描件复制一遍的导入步骤：目录结构本身就是配置。

本页介绍怎么摆文件、扫描器怎么配对语言、怎么把放在别处的文件夹挂进图库，以及几个导入入口各自通向哪里。

它解决什么问题 ​

漫画扫描件的文件夹结构千奇百怪：Vol.14/Japanese/ch01、点兔第14卷/ja/172、manga/zh-cn/172。你希望有一个书架统一列出卷和话，把每种语言的第 1 页和其他语言的第 1 页对上，缺文件时直接告诉你缺在哪——而不用先重命名或搬运任何东西。

  • 卷 是 raw/ 下的任意一级文件夹。
  • 话 是语言目录内的任意文件夹。各语言的话会取并集，所以某个版本可以整话缺席。
  • 页面按排序位置配对，不是按文件名。 每种语言先做自然排序（连续数字按数值比较），再按索引配对。1.jpg、2.jpg、10.jpg 会乖乖排对。

语言目录名 ​

扫描器会先规范化文件夹名（转小写，空格和下划线换成连字符），再与别名匹配：

语言可识别的目录名
日语（ja）ja、jp、jpn、japanese、ja-jp、日、日本語、日文
中文（zh）zh、zh-cn、zh-hans、zh-sg、cn、chs、zh-tw、zh-hk、zh-hant、cht、tw、hk、中、中文、繁中、简中
英语（en）en、en-us、en-gb、us、uk、eng、english、英、英文

文件夹名认不出来时，这一卷照样出现，只是挂一条警告。打开 卷设置（卷所在行的齿轮）把目录指定给某种语言。选择保存在 data/library.json：

json
{
  "volumes": {
    "点兔第14卷": {
      "dirs": { "ja": "raw-ja", "zh": "raw-zh" }
    }
  }
}

一卷能挂多少种语言，取决于你映射出多少；内置的三种只是常客。对照阅读只提供当前页实际存在的语言。

卷设置 ​

卷设置是给“目录没好好自我介绍”的卷准备的修理间。点击卷所在行的齿轮打开。

  1. 对话框会为这一卷识别到的每种语言各列一个下拉框，另外默认提供 日语、中文 和 英语。
  2. 为每种语言选对应的子文件夹。不使用 / 自动 表示交回给自动识别。
  3. 点击保存。图库会重新扫描，这一卷的语言标记随之更新。
  4. 从图库移除只删掉 raw/ 下的链接；原文件夹里的图片和 data/pages/ 里的标注都还在。

一个文件夹只能归一种语言；已经被占用的文件夹会从其他下拉框里消失。如果一个语言文件夹都没识别出来，对话框会直说，并把这一卷的警告原因复述一遍。

先定好映射，再开始标注

分格和笔记按卷、话保存。之后修改映射，页面数据就可能找不回来。请先设好映射、打开几页确认，再动手修分格。

添加位于其他位置的文件夹 ​

＋ 添加漫画 有两种模式：

模式结果
路径留空在 raw/ 下创建一个空文件夹。
选择已有文件夹在 raw/ 下创建一个指向原目录的目录链接。图片不会被复制；链接的行为与普通文件夹一致，因此标注仍可正常写入。

可选：为这一卷指定一个不同的显示名称。输入框下方的提示会重申预期的目录结构：language/chapter/page.jpg。

从图库移除（位于卷设置）只删除 raw/ 下的链接；原文件夹中的图片不受影响，已经保存到 data/pages/ 的标注也会保留。

在普通浏览器中弹不出文件夹选择框。请直接填写绝对路径，或使用桌面版并点击 选择文件夹…。

页面与语言的角色 ​

有三种容易混淆的“角色”：

角色在哪里选择影响什么
底图切格工作台工具栏在哪种语言的画面上画分格。分格矩形由该页的所有语言共用。
对照语言对照阅读的语言标签显示哪些语言、以什么顺序显示。不必启用所有语言。
首选语言PNG 导出整页与单格 PNG 使用基准语言；三语拼图使用所选的对照语言。

分格与笔记按页面存储一份，而不是每种语言一份。对齐偏移按语言存储，也可以按分格存储。

你会看到的警告 ​

图库警告只是碎碎念，不是报错：页面照样能开。

警告含义处理
未识别到语言目录没有任何子文件夹匹配别名。在卷设置里手工映射，或重命名。
未识别的目录：…语言目录旁边还有其他文件夹。映射它们，或直接忽略。
各语言页数不一致各语言的文件数量不同。配对按索引进行；补齐或删除缺失的那一页。
本话扩展名混用例如 .jpg 与 .png 交替出现。通常无妨；如果在意缩略图一致，可统一格式。
文件名与页序不符文件名开头的数字与它的排序位置不一致。如果这种不一致意味着缺页或多页，请重命名。

特殊目录结构 ​

默认结构能覆盖大多数图库。如果你的目录把系列放在最前面、把语言放在最后，或者根本没有语言文件夹，打开目录识别规则…，用占位符描述路径即可。规则按顺序尝试，第一条匹配的生效；它只影响识别，不会重命名或移动文件。

完整语法、规则字段和预览流程见目录识别规则。

导入、交换与恢复 ​

侧栏里有四个不同的入口，各自负责不同的事：

入口用途
添加漫画把已有图片文件夹链接进图库。
工程文件…导出或导入 .mnproj 包（图片 + 标注 + 模板 + 语言设置）。
交换文件…传递 .mntpl 版式模板、.mnexp 导出模板，或单个 .mnpage.json 页面。
备份 / 恢复把 data/ 打包成 ZIP，或恢复之前的 ZIP。

导入会先校验，原文件会备份到 data/backups/。文件内容和版本规则见工程文件与格式。

导入顺序

想把标注恢复到同一台机器上，用备份恢复。换到另一台机器时导入工程。只想分享一个版式、一种导出样式或一页时，用交换文件。

常见坑 ​

  • 重命名文件会改变它的页位置。 配对按排序索引进行；在中间插入一页会把其后所有页后移。把新页加在末尾，或整话统一重命名。见预处理与重命名。
  • 缺一种语言不是错误。 页面仍可打开，对照阅读会为缺失的语言显示占位。
  • 目录链接不是副本。 移动或删除原文件夹后，图库会失效。移动后请重新添加该文件夹。
  • WebP 可以显示，但不会解码用于检测。 依赖自动切格时请使用 JPEG 或 PNG（见切格工作台）。
  • 以侧栏为准。 如果某一卷或某一话没有出现，先检查文件夹名大小写和语言别名。
  • 语言下拉框里找不到某个文件夹。 它已经在卷设置里分配给了另一种语言。
