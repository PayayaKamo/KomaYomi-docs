用語集 ​

このマニュアルの3言語版は、以下の用語を統一して使います。本文と UI ラベルが食い違う場合は UI ラベルを優先し、判断に迷ったらこの表を参照してください。

翻訳者と多言語で読み比べる読者のための共通辞書です——コマ / panel / 分格 が三つ巴なのは事実で、意図的でもあります。

UI ラベルは表示中の言語で変わるため、ボタンの文言が本文と少し異なることがあります。翻訳時と多言語で読み比べるときの共通リファレンスです。

避ける表現 ​

避ける使う理由
画像（スキャンページの意味で）ページ「画像」は書き出した PNG と紛らわしい。
切り抜き枠コマ切り抜きは書き出し操作で、保存されるのはコマ矩形。
翻訳比較本アプリは版を比較するだけで、翻訳はしない。
同期（注釈に対して）保存注釈はローカルに書くだけで、アップロードしない。
テンプレート（単独で）コマテンプレート / レイアウトテンプレート / エクスポートテンプレート3つの別物が同じ語を共有している。
