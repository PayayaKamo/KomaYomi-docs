KomaYomi（格读）漫画をコマ単位で精読する

同じページを日・中・英で。ノートと注釈は絵に貼ったまま。ローカル優先、アカウント不要。

はじめる
データ形式

まずコマから

XYカットによる自動検出に加え、手描き、結合、番号付け、再利用できるレイアウトテンプレート。再検出やテンプレート適用のときも、ノートと注釈は絵に合わせて再マッピングされ、失われません。

複数言語を比較

並べて表示または重ね表示、言語ごとのマスク、ホイールズームとパン、さらにページ／コマ／アンカー／グリッドの位置合わせと再利用できるプリセット。

絵に貼るノート

ページ単位・コマ単位の Markdown ノートを種類別の色付きカードで表示。絵の一点にピン留めでき、タグ、出典、スクラッチパッド、全文検索、LLM に貼るためのワンクリック「コンテキストをコピー」も使えます。

持ち出せる出力

画像フォルダ付きの HTML または単一の埋め込みファイルとしてエクスポートし、ページ／コマ／コラージュの PNG と共有画像を書き出し、すべてを `.mnproj` プロジェクトとして移せます。

なぜ KomaYomi なのか ​

漫画を外国語で読むとき、たいてい窓が三つ必要です。原作、翻訳、辞書。さらにノートアプリを開き、書きたい一文の位置はだいたいずれています。KomaYomi（格读）は、同じページの日本語・中国語・英語を一つの窓に並べ、まずコマに分け、Markdown ノートと注釈を絵のその場所に貼れるようにします。作業の単位はページではなくコマです。

ローカル Web アプリなので、ページ画像は raw/ フォルダのまま、コマ、ノート、タグ、注釈は data/ 以下のプレーンな JSON に保存されます。エクスポートしない限り、データがマシンの外に出ることはありません。スキャンは自分で用意してください。学習用のツールであり、漫画の配布サービスではありません。

作者ページ：X · @payayakamo · note · @payayakamo。どちらも作者個人のページで、製品サイトではありません。

3 手順ではじめる ​

  1. 入れる、または走らせる：GitHub Releases からビルドを入手。または npm install && npm run dev で http://127.0.0.1:5173 を開く。
  2. ページを置く：raw/<巻>/<言語>/<話>/001.jpg に置くか、「ファイル → ライブラリフォルダーを開く…」を使う。
  3. 話を開く：初回はコマが自動検出される（下書きとして扱う）。比較リーダーで読み、ノートを書き、書き出す。

インストール方法の詳細、初回のフォルダー構成、コマの修正はインストールと起動とはじめににあります。

現状の概要 ​

KomaYomi（格读）は 1.1.0 です。このドキュメントでは、現在存在する機能と計画中の機能を区別して説明します。

読む — 複数作品のルートを含むライブラリのスキャン、サイドバーのページ一覧 3 表示、コマ検出と手動編集、分割と番号の並べ替え、レイアウトテンプレート、言語別マスク付きの比較リーダー、原版ビュー、1:1 の拡大ビュー、ページ・話をまたぐ前後のコマと自動センタリング、集中モードと読み取り専用モード。
ノートと注釈 — ページ／コマ単位の Markdown ノート、種類付きノート（背景知識・単語・つぶやき、有効な言語ごとに1種類、色を選べるカスタム種類）、絵に貼るピンと件数付きポップオーバー、ノート検索、単一エディター、アンカーと引き出し線付きで言語ごとに分かれたベクター注釈と右クリックメニュー、Undo スタックと連動する操作履歴。
プロジェクトと出力 — 開いた `.mnproj` へ書き戻す保存、デスクトップ版の「名前を付けて保存…」（ブラウザーではダウンロードにフォールバック）、注釈を既定で焼き込む HTML / PNG / PDF（印刷）/ Word エクスポート、Xiaohongshu（RED）向け共有画像、バックアップ ZIP と定期バックアップ、キャッシュ管理、オフライン書き込みキュー付き WebDAV ソース、スキーマ検証付きのアトミック保存と `.bak` ローテーション・同時書き込みロック、CLI バッチツール。
計画中 — 語彙リストのエクスポート。アプリ内での画像形式変換（名前変更と分割は前処理にあります）。より広範な統合テスト。

このサイトで 予定 と表示されているものはまだ実装されていません。コードにない挙動をページが説明している場合は、この注記を優先し、その機能は利用できないものと考えてください。

KomaYomi の 4 つのリポジトリ ​

このサイトが扱うのはデスクトップ完全版です。同じプロジェクトには他に 3 つの形態があります。

  • KomaYomi — デスクトップ完全版（Electron とローカルサーバー）。このドキュメントの対象です。
  • KomaYomi-online — ブラウザー専用版。.mnproj プロジェクトを開いて閲覧・注釈・エクスポートができ、サーバーは不要です。
  • KomaYomi-mobile — Android / iOS 向けの React Native アプリ。HarmonyOS NEXT は現在プレースホルダーのみです。
  • KomaYomi-docs — このサイトのビルド成果物で、CI が push します。ドキュメントの編集はメインリポジトリで行ってください。

各形態は同じページ JSON と .mnproj 形式を共有しており、作業内容は形態間で移せます。
