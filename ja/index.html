はじめる
データ形式

まずコマから

XYカットによる自動検出に加え、手描き、結合、番号付け、再利用できるレイアウトテンプレート。コマ数が一致する場合、以前の注釈は再マッピングされます。

複数言語を比較

並べて表示または重ね表示、言語ごとのマスク、ホイールズームとパン、さらにページ／コマ／アンカー／グリッドの位置合わせと再利用できるプリセット。

持ち運べるノート

ページ単位またはコマ単位の Markdown ノート、タグ、出典、スクラッチパッド、全文検索、そして LLM に貼り付けるためのワンクリック「コンテキストをコピー」。

持ち出せる出力

画像フォルダ付きの HTML または単一の埋め込みファイルとしてエクスポートし、ページ／コマ／コラージュの PNG を書き出し、すべてを `.mnproj` プロジェクトとして移せます。

KomaYomi とは？ ​

KomaYomi（Manga Learner）は、漫画で言語を学び、ノートを取るためのローカル Web アプリケーションです。同じ漫画の日本語・中国語・英語版を並べて読み比べ、その場でノートを取れます。ページ画像は raw/ フォルダに置いたままで、コマ、ノート、タグ、位置合わせのオフセット、注釈はすべて data/ 以下のプレーンな JSON に保存されます。エクスポートしない限り、データがマシンの外に出ることはありません。

著作権のある素材を配布するためではなく、学習や翻訳レビューのために設計されています。自分のスキャンを用意し、アプリにフォルダを指定して、1ページずつ作業してください。

現状の概要 ​

KomaYomi は 0.2.0 で、活発に開発中です。このドキュメントでは、現在存在する機能と計画中の機能を区別して説明します。

現在動作するもの — 複数作品のルートを含むライブラリのスキャン、XYカットによるコマ検出、手動でのコマ編集、コマの分割と番号の手動並べ替え、コマのグループ化とページ版履歴、コマ／レイアウトテンプレート、アンカーと引き出し線付きのベクター注釈、マスクと4種類の位置合わせモードを備えた比較リーダー、言語ごとにページ全体を並べる原版ビュー（個別のズームとパン）、コマ ID による深リンク付きのコマ詳細ビュー、ページ・話をまたぐ前のコマ／次のコマ、集中モード、編集／閲覧（読み取り専用）モード、検索と単一エディターでの編集に対応した Markdown ノート、注釈を既定で焼き込む HTML / PNG / PDF（印刷）/ Word エクスポート、バックアップ ZIP と定期的な自動バックアップ、キャッシュ管理、WebDAV／ネットワークターゲットへのアップロード、オンデマンド LRU キャッシュとオフライン書き込みキューを備えた WebDAV／ネットワーク画像ソース、`.mnproj` プロジェクトのエクスポート／インポート、CLI バッチツール。
計画中 — 語彙リストのエクスポート。アプリ内での画像形式変換（名前変更と分割は前処理にあります）。完全なネイティブモバイルアプリ（レスポンシブな Web UI は狭いウィンドウでも動作します）。より広範な統合テスト。

このサイトで 予定 と表示されているものはまだ実装されていません。コードにない挙動をページが説明している場合は、この注記を優先し、その機能は利用できないものと考えてください。

KomaYomi の 4 つのリポジトリ ​

このサイトが扱うのはデスクトップ完全版です。同じプロジェクトには他に 3 つの形態があります。

  • KomaYomi — デスクトップ完全版（Electron とローカルサーバー）。このドキュメントの対象です。
  • KomaYomi-online — ブラウザー専用版。.mnproj プロジェクトを開いて閲覧・注釈・エクスポートができ、サーバーは不要です。
  • KomaYomi-mobile — Android / iOS 向けの React Native アプリ。HarmonyOS NEXT は現在プレースホルダーのみです。
  • KomaYomi-docs — このサイトのビルド成果物で、CI が push します。ドキュメントの編集はメインリポジトリで行ってください。

各形態は同じページ JSON と .mnproj 形式を共有しており、作業内容は形態間で移せます。
