はじめる
データ形式

まずコマから

XYカットによる自動検出に加え、手描き、結合、番号付け、再利用できるレイアウトテンプレート。コマ数が一致する場合、以前の注釈は再マッピングされます。

最大3言語を比較

並べて表示または重ね表示、言語ごとのマスク、ホイールズームとパン、さらにページ／コマ／アンカー／グリッドの位置合わせと再利用できるプリセット。

持ち運べるノート

ページ単位またはコマ単位の Markdown ノート、タグ、出典、スクラッチパッド、全文検索、そして LLM に貼り付けるためのワンクリック「コンテキストをコピー」。

持ち出せる出力

画像フォルダ付きの HTML または単一の埋め込みファイルとしてエクスポートし、ページ／コマ／コラージュの PNG を書き出し、すべてを `.mnproj` プロジェクトとして移せます。

KomaYomi とは？ ​

KomaYomi（Manga Learner）は、漫画で言語を学び、ノートを取るためのローカル Web アプリケーションです。同じ漫画の日本語・中国語・英語版を並べて読み比べ、その場でノートを取れます。ページ画像は raw/ フォルダに置いたままで、コマ、ノート、タグ、位置合わせのオフセット、注釈はすべて data/ 以下のプレーンな JSON に保存されます。エクスポートしない限り、データがマシンの外に出ることはありません。

著作権のある素材を配布するためではなく、学習や翻訳レビューのために設計されています。自分のスキャンを用意し、アプリにフォルダを指定して、1ページずつ作業してください。

現状の概要 ​

KomaYomi は 0.1.0 で、活発に開発中です。このドキュメントでは、現在存在する機能と計画中の機能を区別して説明します。

現在動作するもの — ライブラリのスキャン、XYカットによるコマ検出、手動でのコマ編集、コマのグループ化とページ版履歴、コマ／レイアウトテンプレート、ベクター注釈（矩形、楕円、矢印、テキスト）、マスクと4種類の位置合わせモードを備えた比較リーダー、検索付き Markdown ノート、HTML / PNG / PDF（印刷）/ Word のエクスポート、バックアップ ZIP と WebDAV／ネットワークターゲットへのアップロード、オンデマンド LRU キャッシュとオフライン書き込みキューを備えた WebDAV／ネットワーク画像ソース、`.mnproj` プロジェクトのエクスポート／インポート、CLI バッチツール。
計画中 — 語彙リストのエクスポート。スケジュールバックアップ。ネイティブのモバイルアプリ。より広範な統合テスト。

このサイトで 予定 と表示されているものはまだ実装されていません。コードにない挙動をページが説明している場合は、この注記を優先し、その機能は利用できないものと考えてください。
