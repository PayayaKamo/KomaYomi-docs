# 基本概念

5つのオブジェクトで、KomaYomi のほとんどすべてを説明できます。

## 巻 → 話 → ページ

```text
raw/<volume>/<language>/<chapter>/<page images>
```

- **巻** はトップレベルのフォルダです。1冊の本、1号の雑誌、1つのコレクション。
- **話** は言語ディレクトリ内のフォルダです。話は言語をまたいで統合されます。
- **ページ** は話内で自然順に並べた *n* 番目の画像です。ページはファイル名ではなく位置で言語間に対応付けられます。

各ページには安定した識別子があります: `(volume, chapter, pageIndex)`。JSON では **0 始まり**の `pageIndex`、UI では 1 始まりの番号です。

## コマ

**コマ** はページ上の矩形で、`0..1` に正規化して保存されます:

```json
{ "id": "p1", "rect": { "x": 0.05, "y": 0.04, "w": 0.42, "h": 0.30 }, "source": "auto" }
```

- `source` は `auto`、`manual`、`merged` のいずれかです。
- `number` は任意で、自動の読み順を上書きします。
- コマの id はページ内でローカルです（`p1`、`p2`、…）。
- コマは言語に依存しません。1組の矩形がそのページのすべての言語に適用されます。

## グループ

**グループ** はコマ id の名前付きコレクションで、見開きや大きなイラストなど複数のコマにまたがる内容に使います。

```json
{ "id": "g1", "name": "見開き大ゴマ", "panelIds": ["p2", "p3"], "number": 1 }
```

グループはページ JSON の一部で、読み書き、インポート、エクスポートで保持されます。<Badge type="warning" text="予定" /> グループを作成・編集するアプリ内 UI はまだ実装されていません。今は JSON を直接編集するだけです。

## ノート

**ノート** はページまたはコマに付ける Markdown テキストで、タグと任意の出典を持ちます。主要な注釈オブジェクトです。

## 注釈

**注釈** はページまたはコマ上のベクターオーバーレイです: 矢印、矩形、楕円、ハイライト、テキスト、バッジ、モザイク、フリーハンドのペン。座標はスコープの枠に対して正規化されます。

```json
{
  "id": "a1",
  "kind": "arrow",
  "scope": "panel",
  "panelId": "p2",
  "points": [{ "x": 0.1, "y": 0.2 }, { "x": 0.8, "y": 0.7 }],
  "color": "#c2410c",
  "width": 3
}
```

データモデル、正規化、プロジェクトのインポート／エクスポートは注釈に対応しており、ページ単位の `annotationsVisible` スイッチもあります。コマ分割ワークベンチには矢印、矩形、楕円、ハイライト、フリーハンド、テキスト、バッジ、モザイクのベクター注釈ツールがあり、注釈はインポート／エクスポートで保持されます。

## 位置合わせ

**位置合わせ** は比較リーダーとエクスポートで適用される言語ごとの変換です:

```json
{ "x": 0.02, "y": -0.01, "scale": 1.05 }
```

- `x`、`y` はコマの幅／高さに対する比率です。
- `scale` は `0.2..4` にクランプされます。
- オフセットはページ単位（`offsets`）またはコマ単位（`panelOffsets`）で保存できます。
- ページは1つの `alignMode` を選びます: `page`、`panel`、`anchors`、`grid`。
- `gridStep` はパーセント（0.1〜10、既定 1）です。

## 読み方向

`readingDirection` は次のいずれかです:

| 値 | 意味 |
| --- | --- |
| `rtl` | 右から左、上から下（日本の漫画の既定）。 |
| `ltr` | 左から右、上から下。 |
| `ttb` | 縦列、右から左。 |

これはコマの番号付けと、エクスポートでのノートの順序を決めます。

## 言語コード

アプリが扱う言語はちょうど3つです: `ja`（日本語）、`zh`（中文）、`en`（English）。巻は1つ、2つ、3つの言語を持てます。ページにない言語は UI で無効になります。

## ページドキュメント

上記のすべては、ページごとに1つの**ページドキュメント**（`PageDoc`）として、`version: 1` で永続化されます。すべてのフィールドは [データ形式](/ja/data-format) を参照してください。

## プロジェクトパッケージ

**`.mnproj` プロジェクト** は、ページドキュメント、テンプレート、プリセット、マニフェストを含み、さらに画像参照または画像そのものを含む zip です。マシン間で作業を移す手段です。[リモート保存とバックアップ](/ja/remote-backup) を参照してください。

## メンタルモデル

```text
Library
└── Volume (raw/<volume>)
    └── Chapter (raw/<volume>/<lang>/<chapter>)
        └── Page (paired by index)
            ├── Panel[]  ──────────┐
            ├── Note[] (page|panel)│
            ├── Group[]            │  all in one page JSON
            ├── Annotation[]       │
            └── Alignment offsets ─┘
```

画像ファイルは読み取り専用の入力です。作業はすべて `data/` にあります。
