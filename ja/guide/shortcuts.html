キーボードショートカット ​

すべてのキーとマウスジェスチャーを1ページにまとめました。テキストフィールドにフォーカスがある間は単キーのショートカットは無視されるため、ノート入力の途中で表示が切り替わることはありません。

このページで解決すること ​

ショートカットはライブラリ、ワークベンチ、比較リーダー、ノートエディタに分散しています。各章を探し回る代わりに、操作を覚える間はこのページを手元に置くか、印刷してモニターの横に貼ってください。

全体 ​

キー動作
[前のページ（話の境界を越えます）。
]次のページ（話の境界を越えます）。
Pコマ分割ワークベンチに切り替え。
C比較リーダーに切り替え。
Sライブラリサイドバーの表示 / 非表示。
Nノート列の表示 / 非表示。
Eエクスポートダイアログを開く（ページを開いている場合）。
?キーボードと操作のヘルプを開く。
Ctrl+Z最後のコマの変更を元に戻す。
Ctrl+Shift+Zやり直す。
Ctrl+Yやり直す（代替）。

ファイル ​

キー動作
Ctrl+Oプロジェクトファイル（.mnproj）を開く。
Ctrl+S現在のページを保存。
Ctrl+Shift+Sプロジェクトとして保存。

これらのファイルショートカットは、入力中でも動作し、デスクトップアプリと同じように振る舞います。

コマ分割ワークベンチ ​

キー / ジェスチャー動作
枠をドラッグコマを移動。
角または辺のハンドルをドラッグ8方向にリサイズ。
空白をダブルクリック既定のコマを追加。
空白の上をドラッグコマを描く。
Shift + ドラッグ新しいコマを正方形に固定。
Alt + ドラッグ吸着を無効にする。
Ctrl クリック / Shift クリック選択にコマを追加、または選択から外す。
矢印キー選択範囲をページの0.2%だけ移動。
Shift + 矢印キー1%移動。
Delete / Backspace選択したコマ（または選択した注釈）を削除。
Enter保存（確認モード）。
Esc変更を破棄（確認モード）。それ以外では注釈ツールを終了するか、マークの選択を解除。

注釈ツールバーには英字のショートカットはなく、マウスのみです。Esc は常に1段階戻ります。選択中の注釈 → 現在のツール → 未保存のページ、の順です。

比較リーダー ​

キー / ジェスチャー動作
Hすべてマスク（マスクの全体切り替えをオン）。
Shift+Hすべて表示（マスクの全体切り替えをオフ）。
ペインをドラッグその言語をパン。
ペイン上でホイールその言語を拡大縮小。
Alt + ドラッグ / ホイール現在のコマだけにジェスチャーを適用。
マスク中のペインをクリック一時的に表示。もう一度クリックするとマスク。

コマの移動には 前のコマ / 次のコマ ボタンを使います。[ と ] がすでにページ移動に使われているため、キーには割り当てられていません。

マウスのみの操作 ​

一部のコントロールには、仕様上キーボードの代替がありません。

  • ペインの区切り：ドラッグでサイズ変更、ダブルクリックで既定値に戻す。
  • 比較リーダーの言語チップの並べ替え：チップをドラッグ。
  • ズームボタン：コマのツールバーの − / ＋。
  • コマテンプレートと位置合わせプリセットの選択。

よくある落とし穴 ​

  • ショートカットが文字を入力してしまう。 フォーカスが input、textarea、contenteditable 要素にあります。先にステージをクリックしてください。
  • H でマスクされない。 フォーカスがノートやツールバーのフィールドにあります。入力中は比較のショートカットは無視されます。
  • E が何もしない。 ページを開いていないため、エクスポートダイアログは使えません。
  • Ctrl+Z でノートが元に戻ってしまう。 テキストフィールド内ではブラウザ標準の元に戻すが働きます。ページ単位の元に戻すはステージ上でのみ機能します。
