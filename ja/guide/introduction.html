はじめに ​

KomaYomi（Manga Learner）は、「1ページを複数の言語で読み比べる」ためのローカル優先 Web アプリです。日本語を勉強していて翻訳版を横に置きたい人、翻訳版と生肉を突き合わせて確認したい人、あのセリフが各版でどうなっているのか知りたい人——どれも歓迎です。ページをコマに分割し、同じコマを日本語・中国語・英語で並べ、Markdown ノート（訳注、写植の相談、語彙メモ）をそのコマに貼り付けられます。

気軽な読書用のマンガリーダーでも、配信プラットフォームでもありません。すべては自分のマシン上で、自分の画像フォルダだけを相手に動きます。

解決する課題 ​

翻訳の勉強は、ページ単位よりコマ単位のほうが捗ります。ただ、同じ本のスキャンを3言語そろえても、そう都合よくはそろいません。ページはずれ、コマの切り出しは違い、文字の位置もそれぞれ。普通の画像ビューアではズームは1段階きり、ノートも取れず、「この吹き出し、3つの版でどうなってる？」と聞くこともできません。

KomaYomi は、その間に欠けている層を足します。

  1. 構造 — コマは正規化した矩形として保存されるので、ズームしてもウィンドウを変えても、書き出しサイズが変わっても枠は生き残ります。
  2. 位置合わせ — 言語ごとに個別にずらして、同じコマをちゃんと重ねられます。ようやく。
  3. ノート — 所見はページかコマに紐付き、タグと出典付きの Markdown で残せます。「あとで覚えておく」はもう作戦にはなりません。

5ステップのワークフロー ​

手順行うことページ
1生肉と翻訳版を raw/<volume>/<language>/<chapter>/01.jpg に整理するか、すでにあるフォルダを指定します。画像の前処理と名前変更、ライブラリとインポート
2ページを開いて自動分割を実行し、枠を手作業で修正します。自動検出は下書きであって、結論ではありません。コマ分割ワークベンチ
3複数言語を並列または重ね表示で読み、位置合わせを行い、確認したい言語をマスクします。比較リーダー
4タグ、出典、スクリーンショット付きのページノートとコマノートを書きます。訳注も大歓迎です。ノート
5学習用 HTML、スライド用 PNG、別のマシン用のプロジェクトパッケージをエクスポートします。エクスポート

画面の構成 ​

ウィンドウには、常に同じ位置にある5つの領域があります。慣れれば指が覚えてくれます。

  • 上部バー — ブランド（ライブラリに戻る）、巻 / 話 / ページ、‹ › のページ矢印、保存インジケーター、コマ / 比較読み の切り替え、読み順のセレクター、UI テーマ、表示言語、ノート、エクスポート。
  • ライブラリサイドバー（S） — 巻 → 話 → ページ。ページごとの警告に加え、マンガの追加、フォルダ規則、プロジェクトファイル、交換ファイル、バックアップへの入口があります。
  • ステージ — 表示の切り替えに応じて、コマ分割ワークベンチまたは比較リーダーを表示します。
  • ノート列（N） — ページノート、コマノート、一覧検索、一時メモ。
  • ペインスプリッター — ライブラリとステージの間、またはステージとノートの間の縦ハンドルをドラッグしてサイズを変更します。ダブルクリックで既定値に戻ります。

ページは任意の数の言語を持てます。比較リーダーの言語チップは、現在のページに存在する言語だけが有効になります。

最初の10分 ​

  1. まずアプリを動かします。リポジトリで npm run dev を実行するか、デスクトップ版を起動して、http://127.0.0.1:5173 を開いてください。
  2. ライブラリに1巻分を認識させます。raw/ に置くか、サイドバーの ＋ マンガを追加 から手持ちのフォルダを指定します。
  3. サイドバーでページを開きます。初回はコマの自動検出が走り、結果は data/pages/ に保存されます。
  4. 2言語を見比べたいときは 比較読み（C）に切り替え、JA と ZH にチェックを入れて、同じコマが上下でそろうまで片方のペインをドラッグします。ページ全体をいじるより、コマ単位で合わせるほうがずっと楽です。
  5. 書き留めたいところが出てきたら ノート（N）を開き、コマを選んで最初のノートを書きます。保存は Ctrl+Enter です。
  6. 最後に E で HTML をエクスポートし、ブラウザで開いてみてください。

実装済みの機能 ​

ライブラリ — 巻をスキャンし、言語フォルダの別名を認識し、ページを並び順で対応付け、欠けているページや命名の不一致を警告します。
コマ — XY カットによる自動検出、追加 / 移動 / 8方向のリサイズ / 結合 / グループ化 / 削除、番号付け、パーセント入力、グリッド生成、コマテンプレート、宣言的レイアウト、プラグイン、セッションをまたぐページ版履歴。
注釈 — 矢印、矩形、楕円、マーカー、フリーハンドペン、テキスト、番号バッジ、モザイク、ページ単位の表示切り替え、PNG エクスポート対応。
比較 — 複数言語、並列または重ね表示、言語ごとのぼかし / 塗りつぶしマスク、ホイールズーム、パン、ページ / コマ / アンカー / グリッドの位置合わせ、保存済みプリセット、言語順のカスタマイズ。
ノート — ページ / コマのノート、ツールバーとライブプレビュー付きの Markdown、タグ、出典、添付画像、一覧検索、LLM 用コピー、一時メモ。
エクスポート — HTML（画像フォルダまたは単一ファイル）、PNG（ページ全体、現在のコマ、3言語コラージュ）、ブラウザの印刷ダイアログ経由の PDF、ページ画像とノートを含む Word（`.docx`）、コマ枠の重ね描き、印刷用スタイル、エクスポートテンプレート。
ストレージ — ローカルフォルダ、マウントしたネットワーク共有、WebDAV。オンデマンドの画像取得と上限付き LRU キャッシュに対応します。
可搬性 — `.mnproj` プロジェクトパッケージ、`.mntpl` / `.mnexp` / `.mnpage.json` の交換ファイル、バックアップと復元の ZIP、バージョン付きスキーマ。

未実装の機能 ​

以下の項目は、登場する箇所で 予定 と表示されます。

  • 語彙リストのエクスポート。PDF と Word はエクスポートダイアログの PDF（印刷） と Word 文書 から利用できます。
  • 定期的な自動バックアップ。
  • アプリ内の画像変換と一括リネーム。取り込み前にファイルを整えてください（画像の前処理と名前変更）。
  • ネイティブのモバイルアプリ。Web UI は狭いブラウザウィンドウでも動作します（下記参照）。

ライトとダーク ​

UI テーマは既定でシステムに従い、上部バーからライトまたはダークに固定できます。エクスポートされる HTML はライトテーマのみなので、スクリーンショットや印刷結果が一定になります。

よくある落とし穴 ​

  • ライブラリに何も出ない。 サイドバーは raw/ だけを走査します。先にフォルダーを追加するか、リモートツリーをマウントしてください。ライブラリと取り込み を参照。
  • 最初のページのコマがずれている。 自動検出は下書きで、結論ではありません。コマ単位のノートを書く前に枠を直してください。あとで再検出すると手作業の修正は失われます。
  • 言語チップが灰色。 そのページにその言語の画像がありません。ページ数と言語の対応付けを確認してください。
  • 別のマシンでノートが消えたように見える。 ノートは data/、画像は raw/ にあります。両方を移すか、.mnproj を書き出してください。プロジェクトファイルと形式 を参照。
  • オフラインで画像取得に失敗する。 オフライン前に開いたページだけがキャッシュされています。バックアップとリモート を参照。

次に読む ​

  • 新規インストール：インストールと起動。
  • 画像の準備がまだ：画像の前処理と名前変更。
  • 画像を追加する：ライブラリと取り込み。
  • フォルダ構成が特殊：フォルダ検出の規則。
  • キーを探す：ショートカット一覧。
  • 問題が起きた：FAQ とトラブルシューティング。
