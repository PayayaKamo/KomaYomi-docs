Library & Import ​

The library is built by scanning raw/ every time the app loads. No database, no import step that copies your scans: the folder tree is the configuration.

This page covers how to lay out files, how the scanner pairs languages, how to link a folder that lives somewhere else, and which import door leads where.

The problem it solves ​

Scans arrive in whatever shape the previous owner left them: Vol.14/Japanese/ch01, 点兔第14卷/ja/172, manga/zh-cn/172. You want one shelf that lists volumes and chapters, lines page 1 of every language up with page 1 of the others, and tells you where a file is missing — without renaming or moving anything first.

  • A volume is a top-level folder under raw/ by default. When several works sit side by side, the volume is the folder inside a work folder, and the work name is shown as the series (the sidebar writes "series · volume"). Both layouts can coexist: the scanner tries the flat volume rule first and falls back to the series rule. See directory rules.
  • A chapter is any folder inside a language directory. Chapters are unioned across languages, so one edition may skip a chapter folder entirely.
  • Pages pair by sorted position, not by filename. Each language sorts naturally (digit runs compared as numbers), then pairs by index. 1.jpg, 2.jpg, 10.jpg come out in the right order.

Page list layouts ​

The three buttons at the top of the sidebar choose how pages are listed inside a chapter:

  • Two-column thumbnails (default) — a grid of cover-sized thumbnails.
  • Single-column thumbnails — one larger thumbnail per row.
  • List — one compact row per page, showing the page number, the languages present (missing ones are dimmed with a tooltip), a ! when the page has warnings, and ✎ n for the page's note count.

The choice applies to every volume and chapter, survives reloads, and is stored per browser in localStorage under manga-memo.page-list-layout; it is not written to data/, so another browser or machine keeps its own setting. Switching layouts keeps the current scroll position.

Language directory names ​

The scanner normalizes a folder name (lowercase, spaces and underscores to hyphens) and matches it against aliases:

LanguageAccepted directory names
Japanese (ja)ja, jp, jpn, japanese, ja-jp, 日, 日本語, 日文
Chinese (zh)zh, zh-cn, zh-hans, zh-sg, cn, chs, zh-tw, zh-hk, zh-hant, cht, tw, hk, 中, 中文, 繁中, 简中
English (en)en, en-us, en-gb, us, uk, eng, english, 英, 英文

If a folder name is not recognized, the volume still appears, wearing a warning. Open volume settings (the gear on the volume row) to pin a directory to a language. The choice is stored in data/library.json:

json
{
  "volumes": {
    "点兔第14卷": {
      "dirs": { "ja": "raw-ja", "zh": "raw-zh" }

  }
}

Volume settings ​

Volume settings is the repair bay for a volume whose folders did not introduce themselves properly. Open it with the gear on the volume row.

  1. The dialog lists a dropdown for each language detected on the volume, plus Japanese, 中文 and English as defaults.
  2. Choose the subfolder that holds each language. Not used / auto hands the folder back to auto-detection.
  3. Click Save. The library rescans and the volume's language badges update.
  4. Remove from library deletes only the link under raw/; the images in the original folder and the annotations under data/pages/ survive.

A folder can belong to only one language; folders already taken disappear from the other dropdowns. If no language folder was detected at all, the dialog says so and repeats the volume warnings that explain why.

The same dialog has a Chapters section listing every chapter of the volume:

  • Remove next to a chapter only unlinks it from the library. The chapter folder, images, notes and annotations stay on disk; removed chapters appear under Removed chapters, where Restore brings them back.
  • Page offset handles pages inserted mid-chapter that shift every later page number: align this language from page N to page M of the reference edition, or leave it empty for no offset. Offsets are stored as pageOffsets in data/library.json; they affect display and pairing only, never file names on disk.

Fix the mapping before annotating

Panels and notes are stored per volume and chapter. If the mapping changes later, the page data can no longer be found. Set the mapping, open a few pages, and only then start correcting panels.

Adding a folder that lives elsewhere ​

＋ Add manga has two modes:

ModeWhat happens
Leave the path blankCreates an empty folder under raw/.
Pick an existing folderCreates a folder link under raw/ that points at the original. Images are not copied, and annotations remain writable because the link behaves like a normal folder.

Optional: give the volume a different display name. The hint under the field shows the expected layout: language/chapter/page.jpg.

If the folder you pick is itself a work or a series (volumes laid out as work/volume/language/chapter/images), the tool links every volume under the raw/ root and records the work name in the series field of data/library.json. The sidebar then shows "series · volume", and volumes that share a name across works stay separate (their ids get the work name as a prefix).

Remove from library (in volume settings) deletes only the link under raw/; images in the original folder are untouched, and annotations already saved under data/pages/ are kept.

In a plain browser there is no folder picker. Type the absolute path instead, or use the desktop build and click Choose a folder….

Page and language roles ​

Three different "roles" are easy to confuse:

RoleWhere it is chosenWhat it affects
Base imagePanel workbench toolbarWhich language's artwork you draw panels on. Panel rectangles are shared by all languages on that page.
Compare languagesCompare reader language chipsWhich languages are displayed, in which order. Not every language has to be enabled.
Primary languagePNG exportWhole-page and current-panel PNG use the base language; the trilingual collage uses the selected compare languages.

Panels and notes are stored once per page, not once per language. Alignment offsets are stored per language and, optionally, per panel.

Warnings you will see ​

Library warnings are gossip, not errors: the page still opens.

WarningMeaningFix
No language directory recognizedNone of the subfolders matched an alias.Map them in volume settings or rename them.
Unrecognized directory: …Extra folders sit next to language folders.Map them, or ignore them.
Page counts differ across languagesLanguages have different numbers of files.Pairing is by index; add or remove the missing page.
Mixed extensions in this chaptere.g. .jpg and .png alternate.Usually harmless; normalize if you care about consistent thumbnails.
Filename does not match page numberThe leading number in the filename differs from its sorted position.Rename if the mismatch indicates a missing or extra page.

Folder rules for unusual layouts ​

The default shape covers most libraries: the flat volume/language/chapter layout and a root holding several works as work/volume/language/chapter/images are both recognised out of the box. If your folders put the language last, have no language folder at all, or skip the chapter level, open Folder rules… and describe the path with placeholders. Rules are tried in order and the first match wins; they only affect detection and never rename or move files.

The full syntax, rule fields and preview workflow are on Folder Detection Rules.

Import, exchange and restore ​

Four different entry points live in the sidebar. They do different things:

EntryUse it for
Add mangaLink an existing image folder into the library.
Project file…Export or import a .mnproj package (images + annotations + templates + language settings).
Exchange files…Move .mntpl layout templates, .mnexp export templates or a single .mnpage.json page.
Backup / restoreZIP the data/ folder, or restore a previous ZIP.

Imports are validated first and the original files are backed up under data/backups/. See Project Files & Formats for the file contents and version rules.

Import order

Restore a backup when you want your annotations back on the same machine. Import a project when you move to another machine. Use exchange files when you only want to share a layout, an export style or one page.

Help?

The URL hash is deep-linkable: #/<volume>/<chapter>/<page>/<panels|compare|original>. Double-click a panel in the compare reader to open its detail view; the URL then gains a /panel/<panelId> segment (for example #/vol-01/01/3/compare/panel/p-2), so refreshing or sharing the link restores the same page and panel.

In the detail view:

  • Every enabled language is shown side by side (stacked vertically on phones and tablets), followed by this panel's notes and annotations.
  • Zoom runs from 100% to 600% with the toolbar buttons, the wheel or a pinch; zooming and panning affect the enlarged images only.
  • The middle arrows switch to the previous / next panel, and the outer arrows turn pages. Arrow keys switch panels instead of pages while the view is open.
  • Esc, the close button or the browser Back button leaves the view and returns to the same page and panel position. A link opened from someone else rewrites the URL instead of adding a history entry.

Thumbnails are generated on demand and cached in data/cache/thumbs/. Deleting that folder is safe; thumbnails are rebuilt on the next visit. The image format is sniffed from the file header, so a .png that is really a JPEG still renders correctly.

Common pitfalls ​

  • Renaming a file changes its page position. Pairing is by sorted index; inserting a page shifts every page after it. Add the new page at the end, or rename the whole chapter consistently. See Preparing & Renaming Images.
  • One missing language is not an error. The page opens, and the compare reader shows a placeholder for the missing language.
  • A folder link is not a copy. If you move or delete the original folder, the library breaks. Re-add the folder after moving it.
  • AVIF, HEIC, GIF and BMP are displayed but not decoded for detection. WebP is decoded. Use JPEG or PNG when you rely on automatic splitting (see Panel Workbench).
  • The sidebar is the truth. If a volume or chapter is missing, check the folder name casing and the language aliases before anything else.
  • A language dropdown does not offer the folder. It is already assigned to another language in volume settings.
