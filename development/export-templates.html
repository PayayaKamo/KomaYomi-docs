Export Templates ​

An export template stores the settings of the export dialog so you can reuse a layout without re-typing it. A template never stores which pages to export — volume, chapter, page range and offsets are chosen at export time.

For the end-user view of exporting, see Export.

Where templates live ​

FileContents
data/templates/export.jsonAn array of template objects, each with the same envelope as an exchange file.
<name>.mnexpOne template, exported for sharing or backup.

The dialog reads the array through GET /api/export-templates and writes it through POST /api/export-templates (save) and DELETE /api/export-templates?id=…. Import and export of .mnexp files go through the exchange endpoints:

MethodPathPurpose
POST/api/exchange/export-template/exportDownload one template as .mnexp; body is { "templateId": "…" } (or { "id": "…" }).
POST/api/exchange/export-template/importImport an uploaded .mnexp; body is { "data": "<file text>" }. Missing id / name / createdAt are filled in, and an existing id is replaced by the imported template.

Fields you can customize ​

FieldTypeUI rangeMeaning
templatetwo-column | stack | compare-wide—Page layout. two-column puts images left and notes right; stack stacks languages; compare-wide uses a wide image grid.
titlestring—Heading at the top of the exported page.
languagesstring[]—Languages included, in display order. Any language id found in the library is accepted.
embedImagesboolean—Inline images as data URLs instead of linking files.
showPanelBoxesboolean—Draw panel outlines over each image.
includeNotesboolean—Include notes in the document.
onlyWithNotesboolean—Skip pages that have no notes.
printboolean—Emit a print-ready page that opens the browser print dialog (Save as PDF).
noteFilterTagsstring[]—Show only notes carrying one of these tags; empty means no tag filter.
pageWidthRationumber28–75Image column width as a percentage of the content width.
columnGapnumber0–64Gap between columns, in pixels.
fontScalenumber0.8–1.4Note text scale. 1 is 100%.
columnsnumber1–4Panels per row in the panel-compare layout.

volume, chapter, pageIndices and offsets are part of the runtime ExportConfig but are deliberately excluded from saved templates.

config is partial in storage: a template saved from the dialog contains every field it controls, but a hand-written file may omit keys and let the defaults fill them (two-column, 漫画对照批注, ja/zh/en, pageWidthRatio 46, columnGap 28, fontScale 1, columns 1).

Applying a template ​

  • In the dialog. Open Export, pick a template from the list, then adjust the page range if needed. Saving stores the current layout under a name.
  • By file. Exchange dialog → Import → choose the .mnexp. It appears in the template list immediately. If a template with the same id exists, the import replaces it.
  • By API. POST /api/export accepts a full ExportConfig; build it from the template's config plus the scope you want:
json
{
  "volume": "点兔第14卷",
  "chapter": "172",
  "pageIndices": [0, 1, 2],
  "template": "two-column",
  "title": "漫画对照批注",
  "languages": ["ja", "zh"],
  "embedImages": false,
  "offsets": { "zh": { "x": 0.01, "y": 0, "scale": 1.02 } },
  "showPanelBoxes": false,
  "includeNotes": true,
  "onlyWithNotes": false,
  "noteFilterTags": ["语气"],
  "pageWidthRatio": 52,
  "columnGap": 24,
  "fontScale": 1.1,
  "columns": 1
}

Unknown fields ​

exportConfigSpec in shared/format.ts allows unknown keys, so a template written by a future version survives a round trip through this one. The current UI ignores keys it does not render; they are not deleted. print is a good example of a field the exporter understands even though older docs did not list it.

When a template seems to do nothing ​

SymptomLikely cause
Imported template does not appearThe dialog list is loaded once; reopen the dialog. The API validates the whole file and rejects a malformed config with a field path.
languages shows an unexpected orderThe export uses the template order, filtered to languages that exist in the selected volume.
Pagination differs from the previewpageWidthRatio, columnGap and fontScale affect print/PDF output; the on-screen preview approximates them.
The same name appears twiceImports with a colliding id keep the name and add a suffix, so two templates can share a label. Rename in the dialog after import.
